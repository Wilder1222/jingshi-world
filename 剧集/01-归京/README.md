## 第04至36集分集大纲摘录

以下为大纲原有行动与关系后果，非完整对白台本；统一修改入口为全剧大纲。

<a id="gj-ep04"></a>

## GJ-EP04｜旧衣

状态：**分集大纲**。旧别名：EP04、归京04。日期／时段：廿四。

**当前行动、阻力与结果：**程叙带衣食来，帮办军引核验；今顾以记忆不全解释旧事，接受原本给原顾的亲近。傍晚温九山接报赶到，先查看伤情、确认已稳，让他休息；旧招和运息的系统检查留待第6集，不展开师门履历

**关系变化与后果：**本集关系中心仍是发小。温到场即照看伤者，不在同一场再让师妹师弟排队亮相

<a id="gj-ep05"></a>

## GJ-EP05｜听不懂也要听

状态：**分集大纲**。旧别名：EP05、归京05。日期／时段：廿六。

**当前行动、阻力与结果：**程叙带今顾勾栏听曲，两人对结尾争执，仍把整折听完。回程买材料给顾伯补窗，许娘在街边卖灯穗

**关系变化与后果：**一次正常出门完整结束。今顾开始喜欢这里，不需要每处摊位都藏证据

<a id="gj-ep06"></a>

## GJ-EP06｜路不是这样走的

状态：**分集大纲**。旧别名：EP06、归京06。日期／时段：同日。

**当前行动、阻力与结果：**温正式检查，发现顾砚连多年旧步法也不熟，先按伤后失调处理，教他重新找支点、收势；不施识魂术。今顾与韩、杜等复核桥外地形和九阵击退敌人的经过，另循王寿租单查车行，分清两队行动；不要求今顾复现原顾的识阵本领

**关系变化与后果：**温认识的是原顾，异常会累积。九卒能准确说明各自看见的袭击，却不能凭伤口或修为认出雇主；师父也不代破案。其余老卒在邻近办退籍安置和日用事务，不因调查便突然消失

<a id="gj-ep07"></a>

## GJ-EP07｜谁的工钱

状态：**分集大纲**。旧别名：EP07、归京07。日期／时段：廿七。

**当前行动、阻力与结果：**车行曾从沈氏货栈调借王寿租用的车辆。20岁的沈蘅先处理陶七欠薪，再比对借还手续；她主持获授权的长京货栈经营，要求今顾出示相关凭单，不接受只凭顾家名头查账

**关系变化与后果：**沈年轻却已须顶事，仍有经验和权限的边界；陶七先是为自己讨钱的人。两人先认清彼此做事的分寸，亲近尚未发生

<a id="gj-ep08"></a>

## GJ-EP08｜不能只凭一张纸

状态：**分集大纲**。旧别名：EP08、归京08。日期／时段：廿九。

**当前行动、阻力与结果：**车行、货栈和付款经手互证，追到安排冒役的承办人；巡防另循桥外走访、黄祁被九阵所伤后的求医及住宿去向调查行刺。九卒分别作所见范围的证词，不用九人重复同一句话充作九份独立来源。两条行动链出现共同经费经办线索，仍须分别查清

**关系变化与后果：**材料及时交官署。沈认交易，老卒说明亲历，今顾比较疑点；打赢刺客提供了追查伤者的线索，但不是已经证明梁买凶

<a id="gj-ep09"></a>

## GJ-EP09｜年饭

状态：**分集大纲**。旧别名：EP09、归京09。日期／时段：除夕至初二。

**当前行动、阻力与结果：**冒役者被扣，调查等待核办。九卒各凑自己的那份饭钱，和顾伯为多出来的铺盖、锅灶及年菜忙碌，饭桌谈亲人、手艺和退伍后的合伙生计；没有新敌人打断。初二，旧案文书使外库加严封存，长京支枢开始本轮补稳，南水关随之失稳

**关系变化与后果：**原顾藏信早于本轮失稳，未穿完好官封。九人的食宿来自有限安家钱与实际商量，不让顾伯一份旧俸凭空养活全队；年饭仍有真实安定

<a id="gj-ep10"></a>

## GJ-EP10｜肯作保的人

状态：**分集大纲**。旧别名：EP10、归京10。日期／时段：正月初三。

**当前行动、阻力与结果：**谢鹤年公开担保，争取限定核验与居家候问，承担被追责的名誉风险；条件是材料如实交代。今顾接受，没有把自己的全部推断交给他决定

**关系变化与后果：**谢正式展开为有实际作用的长辈。后来的揭底不能取消这次帮助与感激

<a id="gj-ep11"></a>

## GJ-EP11｜留不住的字

状态：**分集大纲**。旧别名：EP11、归京11。日期／时段：初四。

**当前行动、阻力与结果：**清点外库时，南水关旧泊位相关水程页出现前后差异。今顾先查水损、人为换页与形成时间；内侧仍无拆检许可，顾伯只知道旧库结构

**关系变化与后果：**首次展示记录异常，不立即解释世界。相关字句与受影响对象对应，并非纸上所有内容一起消失

<a id="gj-ep12"></a>

## GJ-EP12｜城外那一单

状态：**分集大纲**。旧别名：EP12、归京12。日期／时段：初六。

**当前行动、阻力与结果：**巡防依黄祁伤后去向、现场和经手资料扣到承单人及执行者，再核住宿、付款与罗顺救走黄的经过，桥外执行链闭合；与冒役链共有的上游经办指向梁所属机构，仍缺本人授权

**关系变化与后果：**九卒的胜仗与官署随后拘捕相衔接。韩、杜等确认原顾被护回后仍能清醒行动；九人击退了刺杀，却不知道府内另有断籍决定

<a id="gj-ep13"></a>

## GJ-EP13｜有人在家

状态：**分集大纲**。旧别名：EP13、归京13。日期／时段：正月十二。

**当前行动、阻力与结果：**许娘被“户绝”报告要求交宅，她自己找工匠与写状人，并请同街办事的程叙协助。程认出买方担保与父亲有关，想先私下退宅，暂未说全

**关系变化与后果：**普通造假进入主角生活。程维护旧情的信念第一次直接伤害了另一人的申诉

<a id="gj-ep14"></a>

## GJ-EP14｜灯架下

状态：**分集大纲**。旧别名：EP14、归京14。日期／时段：十三。

**当前行动、阻力与结果：**22岁的宁清晏年度巡查入京，先在灯架事故中稳住结构；今顾配合匠人安排撤离。事后她认出宅产核验上自己的签署：此前根据地方“已实勘”呈报同意移交

**关系变化与后果：**宁先以能力和职责登场，也已有判断责任。她不能站在案外只批评坏官

<a id="gj-ep15"></a>

## GJ-EP15｜还没看过，就写好了

状态：**分集大纲**。旧别名：EP15、归京15。日期／时段：十四上午。

**当前行动、阻力与结果：**许娘指出屋内改建细节，沈协助核交割；独立工班出勤证明首次实勘晚于终验签结，与“亲见无人居住”的报告矛盾。宁暂缓执行并要求复核

**关系变化与后果：**指向具体虚假陈述，不把提前写表误作预知未来，更不把许娘直接写成失世者

<a id="gj-ep16"></a>

## GJ-EP16｜那个签押

**当前行动、阻力与结果：**程家短场中，程守成愿退钱，却让儿子换一句“担保时不知情”；程叙拒绝，随后交出文件、承认隐瞒。今顾不删呈文中的程家责任，许娘继续申诉

**关系变化与后果：**程父以具体过错短入，不另开家族阴谋。程失去双方信任；今顾要求朋友诚实，自己也仍在隐瞒

**关系变化与后果：**一案先兑现小胜，产权和赔偿仍待审理。宁开始改变做事方法

**关系变化与后果：**整集无袭击、无新命案。宁允许一个公务之外的愿望，关系靠真实相处生长

## GJ-EP19｜有人要付账

**当前行动、阻力与结果：**沈氏货物暂扣，章秋屏划明工钱与可用担保，保留自己的管事立场。一次收栈，今顾留下帮沈整理受潮货样；她替他掸去领边纸屑，两人忽然站得太近，手都迟了半拍才收回。他主动约她次日晚间去喝热汤，她先说还得忙，最后仍问了时辰；两人到时真赴了约，吃完才各自回家。另场叶扶疏听师父说伤势趋稳，进京送换季衣与材料，发现大师兄接物、练步都与从前不同。众人仍申请核验关印、验货和补卷经手

**关系变化与后果：**沈与今顾先有轻微而双向的心动，一次约见不夹索款或送证据。叶以旧同门关系正式展开；章、叶原有行动保留，商号日常压缩重复工钱说明而来

## GJ-EP22｜记得，不能代替证据

**关系变化与后果：**陆作权限决定，高负责实际勘验；首次只呈现岗位与办事习惯，不加个人长篇身世

## GJ-EP23｜墙后少的一尺

状态：**分集大纲**。旧别名：EP23、归京23。日期／时段：当日午后。

**当前行动、阻力与结果：**今顾绕库门内外对照，发现同一侧外墙到转角尚有一段，室内却已收墙，猜墙后另有空间。高成礼复尺，工匠排除普通墙厚等解释，在已获许可范围内拆检，找到内室与近期使用痕迹。内室于本轮失稳后首次开启，立即读返京前写成的信，另取一页观察离室变化

**关系变化与后果：**先有可见尺寸疑点，再有大胆猜测和测拆结果。开启后的缓冲最多一夜，关门不重置；专业核验由高与工匠完成，不给主角透墙神通

## GJ-EP24｜留给后来的人

**当前行动、阻力与结果：**读完整信，结合遗留旧图、使用痕迹、韩青与顾伯记述，补全原顾藏信、独处和主动断籍的事实。信不预知桥外袭击，也没有谢的姓名

**关系变化与后果：**屋内死亡不是补刀。遗信证明意图，不能独自证明全部跨世界规律；原顾仍须承担利用未知者的责任

**当前行动、阻力与结果：**今顾向程说明自己没有原顾的意识与过往。程先问故友是否留下话，得知没有单独附信，无法立刻接受；仍照约为陶七找车

**关系变化与后果：**哀悼与道义可以同时存在。程不把继续救人当作当场认新兄弟

<a id="gj-ep26"></a>

## GJ-EP26｜她有权知道

状态：**分集大纲**。旧别名：EP26、归京26。日期／时段：当日晚。

**当前行动、阻力与结果：**今顾分别向沈、宁、顾伯及温、叶说明原顾选择与自己的来处；宁保留主要的情感对话。沈只先追问，货栈与汤摊上相处的是否一直是眼前人；得到肯定后，她承认那些记忆是真的，却还需要想一想。今顾不逼她立即宽慰自己。当夜另向九卒全员讲清，九人全部得知原顾已死与来客身份；有人先问原顾留下什么，有人暂不再沿用旧称，有人只确认已答应的接应仍做。亲笔信寄贺、宋，月底收到
