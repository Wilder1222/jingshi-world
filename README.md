# 《经世》创作工作区

剧情版本 **v1.3** · 美术设定 **v0.8** · 分类管理 **v1** · 更新：2026-09-07。

当前正典：[人物行为与群像总则v1.0](设定/人物行为与群像总则.md)、[乾朝社会与制度运行v1.0](设定/乾朝社会与制度运行.md)、[世界观与终局v1.3](设定/世界观与终局.md)、[重境、修行与承接机制v1.3](设定/重境、修行与承接机制.md)与[终局多方知情与彼端主体v1.3](设定/终局多方知情与彼端主体.md)。四位主角各有独立生活与支线，却不设根本利益冲突或爱情零和；所有层级人物都要以自己的处境、能力和选择行动。旧境是真实变化中的彼端，重境是可测的局部接合，主录是人为调度账而非改写现实的神书；权势或修为不等于全知，终局仍由谢、皇权、工程与钱粮共同维持、又彼此牵制。河湾一侧有局部拒绝权，却不是第五个总控势力；拆的是人为强并，不是永封旧境。两名新增主事、守一执令修士和河湾代表暂不具名、不登记角色编号；[幕后群像与权力结构v0.9](设定/幕后群像与权力结构.md)保留为讨论沿革和后续细化依据。

本轮确立人物与画面的审美：全员好看、各有特色，以高端华丽古装剧为底子。[美术风格与造型总则](资产/美术风格与造型总则.md)统领角色骨相、衣装、仪态及场景质感，文字方向已分入角色与场景卡。

既定整体语气：日常略带轻松幽默，认真时从细致观察、大胆推测到主动实施。主角不替全城处理公共事务；重要支线必须改变主线、人物的关键选择或情感结局。执行方法与现有剧情示例见[叙事风格与主角行动](设定/叙事风格与主角行动.md)，已有前三集保持原有事件与资产，不强塞后期权力网络。

三位女主继续为沈蘅20岁、宁清晏22岁、殷照夜19岁，均有与男主的双向爱情与独立人生线。宁的克制坚定、殷的鲜活决绝按本作经历发展，不复制外部作品的既定对立或命运；关系见[三位女主与感情线](设定/三位女主与感情线.md)。

资产按角色、场景、道具分类，前三集按集独立保存。每集末尾列所需资产，每张资产卡末尾反查出场剧集与场次。现有内容均为文字创作，图片、配音和视频尚未制作。
