# 角色资产索引

当前共60张角色卡，编号C01—C60。每个人只有一张卡，跨线关系用标签检索；以下按主要归类列出，编号不会因出场顺序或分类变化重排。

全60张卡都有v0.8造型字段；C60只定义遮脸轮廓，面孔、性别和具体年龄未定。共同依据见[美术风格与造型总则](../美术风格与造型总则.md)，年龄、身份与出场次序以各卡现行小传为准。

C01—C23、C57—C60为文字设定，C24—C56仍为大纲登记。56人的顺序传记见[主角与近人八人](../../设定/人物传记-主角与近人.md)、[群像与对手48人](../../设定/人物传记-群像与对手.md)；C57—C60当前仅有角色卡内的本场动机和边界，不冒充已有完整生平。四个未具名职务的末尾草稿仍不分配C号。文字设定与推演不表示已制作定妆媒体。

前三集是27个角色身份、24个露脸造型＋1个遮脸轮廓＋1个画外声位。C01原顾与C02今顾共用face-C01古装形象；C05杨舟只用voice-C05画外声。其余角色的face键只登记文字形象，未生成媒体；后续角色visual_key均为null。九卒固定为C03、C16—C23，共九人，不含顾砚。街景群演不冒充具名人物卡。

机器检索数据见[characters.json](../../索引/数据/characters.json)。故事依据见[世界与终局](<../../设定/世界观与终局.md>)、[全剧大纲](<../../剧集/全剧大纲.md>)及[制作约定](<../制作约定.md>)。

当前三位女主为沈蘅20岁、宁清晏22岁、殷照夜19岁，均有与陈渡的双向爱情和独立生活线；见[三位女主与感情线v1.0](../../设定/三位女主与感情线.md)与[人物行为与群像总则](../../设定/人物行为与群像总则.md)。四位主角不设根本利益冲突，角色卡中的行为、关系与责任应服从该总则。年龄按各自首次正式登场时计。

## 使用说明

- 检索‘顾砚’会同时命中原顾与今顾，这是同脸不同身份，不合并人物责任。
- 韩青与韩骁是不同角色；孙福生、周成、丁茂等普通街坊不增设阴谋身份。
- 顾父按当前主稿称谓登记，宋知微为顾母；没有从早期冲突版本补入姓名或年龄。
- 陶七女儿与陈渡母亲尚未命名、未扩写，只登记大纲中已存在的独立关系动作。
- 索引维护只整理当前文字。新增或修改人物设定须先更新故事源头，再同步卡片与JSON。
