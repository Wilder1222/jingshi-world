## 未另设编号的现有物件

许照邻的方口行囊、顾砚私人零钱、灶边糖盐罐等已在19、20中写明，仍按原场次追踪，不为本轮检索拆分新增P号。它们分别不得混成P02顾砚行囊、P18共同饭钱或P15前厅小糖罐。门院小案、固定大案、铜镜和窗闩的原有摆放见相应[场景卡](../场景/README.md)。

P05仅为旧版停用记录，不能恢复“空灰袋诱抢”；P13不能因为已有资产卡，就在前三集补拍信封或机关。
