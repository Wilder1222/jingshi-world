# 叙事风格与主角行动 v1.2

**v1.7知情修订：**按[穿越隐秘与现代知识运用](穿越隐秘与现代知识运用.md)，穿越前中期不向配角透露，女主不默认例外，后期公开节点待定。现代感落在低调的方法、试验和判断，不靠自报来历、术语炫耀或贬低本地专业者。主角守密仍须讲清他人的实际风险与已有感情；下文的亲历、署名只指可公开的当地行动，不指现代经历。

用户确定：**整体略带轻松幽默；认真的时候非常有逻辑；从细致观察入手，大胆推测和实施。整体剧情组织要紧凑，剧情推进与情节组织更接近美剧、韩剧的方式。**v1.0明确顾砚不负责所有人的问题，前四篇持续推进同一核心任务；v1.1补充四位主角各有独立人生、没有根本利益冲突，主要、次要与短暂人物都要有自己的选择与后果。v1.2将紧凑结构落实为因果推进、阶段兑现与关系递进，并补明后三篇有限任务的起因和完成边界。完整人物行为核验见[人物行为与群像总则](人物行为与群像总则.md)，篇章与单集组织见[剧情结构与推进](../剧集/剧情结构与推进.md)（结构工作稿v1.6）。本页将这些原则作为全剧共同写法，落入主角表演、单集对白和大纲推进。

日常让人愿意和这些人物多待一会儿；危险发生时，让人相信他们知道自己在做什么。陈渡平日有好奇心，能打趣，也会窘迫；一旦发现真正的异常，话会变短，眼睛开始追着具体的人和物走，随后作出决定。

画面审美按[美术风格与造型总则](../资产/美术风格与造型总则.md)执行：人物各有吸引力，衣装与场景有高端华丽古装剧的精良底子。漂亮的人也会拿错糖罐、害羞或害怕；严肃时把面部神情、动作和关键细节拍清，让美感与人物逻辑相接。

## 紧凑的因果与持续的关系变化

本作采用的“美剧式”方法，是让人物目标、主动行动、对手或环境的反应相互推动，在推进中形成改变下一步做法的中段转向，并在单集和阶段结尾兑现结果；采用的“韩剧式”方法，是让关系逐步积累，行动留下情感后果，旧日细节在新的相处里产生回响。按用户本轮补充，中式的人情、家国、礼数与余韵也进入同一套组织方法，具体见[中式叙事补充](../剧集/剧情结构与推进.md#chinese-narrative)。这些是《经世》选择的写法，不作为对所有中、美、韩剧的概括，也不把不同方法限定为某一地独有。

中式部分让人物带着家族、师门、同袍和街坊关系办事：恩情影响开口的难度，当前承诺决定实际出力的范围，家国责任从已经认识的人和日常生活中生长。谢的帮助与他的责任同时写清，程家赔付进入之后的家常，九卒有同袍义气也有各自的家。长线线索和留饭、听曲等细节前后照应，再出现时体现新后果。

对白可有礼数、试探和言外之意，选一个有作用的称谓、等候或动作便够；风险、拒绝、爱情回应与承诺仍须明确。大转折后的生活余波保留，重复表达同一意义的场面合并。人物当下所知按[穿越隐秘规则](穿越隐秘与现代知识运用.md)执行，不以“默契”暗示旁人已懂穿越。家庭和师门的分量也不改变三位女主的独立选择。

**每个单集先确定一个主要问题，再安排A事件线与B关系线。**A线回答人物眼下要做成什么、受到什么阻力、采取什么办法；B线回答这件事或这次相处使谁更信任谁、答应了什么、误判了什么，或重新决定怎样相处。背景线只在理解当前行动需要时出现。三者可以在同一场交织，不按角色平均分镜头，也不要求每集列出相同数量的线。

| 组织位置 | 本作要求 |
|---|---|
| 开始 | 让观众较早知道本集主要问题和人物眼下的选择；承接上集已经发生的结果 |
| 推进 | 每一项主要行动都改变局势、信息、可用条件或人物关系，后续行动由这项变化引起；说明尽量落在正在办的事上 |
| 中段转向 | 前一办法得到反馈，使目标变得更具体、办法需要调整或关系理解发生变化；转向须有前因，不固定每几分钟反转 |
| 阶段兑现 | 给出本集问题的实际回答或明确进展，兑现已经作出的承诺、胜场与代价，保留仍未解决的部分 |
| 结尾承接 | 由本集结果产生下一步行动或情感期待；可以是新问题、主动决定或一次有余味的关系变化，不必总靠危险中断 |

生活场也可以成为本集主要内容：一起听完一折戏、允许对方留下灯、接受一件旧衣，都能改变关系、承诺与人物对生活的选择。必要的喘息让观众感受到人物想保住的生活；不强行给每场添线索、袭击或倒计时。A事件线在此类单集中可以只是完成一次出门或相约，B关系线仍须有前后区别。

压缩优先处理重复解释、同一情绪的多次确认，以及不改变局面的搬物和往返。同一信息已经被动作说明，就不再让几个人各说一遍；同一关系判断已经成立，后续相似场面须带来新的发现、承诺或后果，否则合并。证物来源、关键选择、九卒的真实胜果与人物所需的情感停顿仍须拍清，不能用删掉因果换取表面速度。

## 主线优先，而非主角包办

顾砚在前四篇的固定外部任务是：**沿顾家旧案与原顾之死，查出仍在追索、利用自己的幕后计划，并在它完成前阻断它，摆脱这场布局对自己人生的控制。**这一阶段在《众名》完成真实的阻断、救援与责任追究。后三篇由既有成果和顾砚公开接应事迹被冒用，引出撤回署名、核实越权、完成有限往来与争议处置的新任务；现代经历仍保密。每项任务有具体对象和结束条件，陈渡可以完成后回到自己的生活。新冲突不能撤销已查清的责任、九卒与宁的胜利，或把旧敌重置成更高层幕后。完整世界与终局依据见[世界观与终局](世界观与终局.md)，后三篇仍依[七篇章推演](多端世界与七篇章推演.md)的工作稿边界发展。

| 篇章 | 眼前阶段任务 | 与本阶段任务的关系及完成边界 |
|---|---|---|
| 归京 | 查追杀、旧物与原顾留下的东西 | 从被动求生转为知道有人仍在布置自己 |
| 照夜 | 找关键人和材料，核实谁筛选、引导原顾 | 分辨保护、利用与控制不是一回事 |
| 白河 | 查家案、世隙与旧工程，找出计划全貌及弱点 | 证明揭穿一人不足以终结既有结构 |
| 众名 | 用此前争取的条件阻断闭合线 | 把同一任务完成为一次有代价的行动，而非临时改当救灾总负责人 |
| 渡世 | 撤回被冒用的署名，完成一次有退出余量的小批往来 | 从已经取得的成果受到挪用进入新任务；试运有用、亏损与停用都保留为实际结果 |
| 天倾 | 查清早年停用事实，阻止预排工期吞并现场决定 | 核实当前越权及其依据，完成有限的阻止行动；不将过去所有成功改判为骗局 |
| 经世（上卷彼岸／下卷经世） | 终止对顾砚有限接应事迹与见证资格的独占征用，完成首次拒绝与费用争议处置 | 让陈渡获得结束外部任务的选择；不公开现代经历，保留不参加者的生活；现代亲友尾声不提供返乡办法 |

阶段任务会完成，局部敌人会败退，已取得的结果继续影响后续选择；下一任务必须有具体的新起因，不能靠宣布此前白做维持篇幅。暗线可以是对手在行动，或顾砚暂不让观众知道全部布局；观众仍应知道他眼下想办成什么，以及办不成会失去什么。悬念应是“他怎样做、是否做成”，不是连续多场以后仍不知他为何在场。

世界观背景不等于必须拍成支线。顾砚可以顺手拉一把眼前遇险的人，也可以不介入陌生戏院、商号或街巷里的问题；同一件事发生在他在意的人身上，他愿意多走一步，是人物的偏爱，不是待纠正的缺点。沈、宁、殷各自判断并完成自己的事，顾砚参与的是她们愿意让他参与、且与共同冲突相交的部分。

筛选一条需要完整展开的支线，先问：删掉它后，主线的进程、条件、代价、关键选择、终局，或人物最终的情感结局会不会实质变化？会，才值得占用篇幅；不会，只是说明乾朝很真实或某职业很辛苦，便留作背景细节、短场或人物口中的后续。

爱情与日常可以没有线索、暗号或证物。一场约会能只让两人作出承诺、暴露欲望、改变信任，或让观众看见他们想保住的未来；节日和听曲也可以完整平安地结束。若一场戏只重复“人很好”或“相处开心”，而没有新的关系变化、人物发现或节奏作用，才应压缩。

## 四人并行，群像有自己的路

陈渡、沈蘅、宁清晏、殷照夜可以因信息、专业、时间和风险判断不同而互相校正，却不把爱、保护或善意写成替对方决定人生的资格。分歧要落在可查、可说、可补的行动上；不是逼谁站队、让谁牺牲退出，或用长期误会代替人物发展。

同样，配角的镜头不因短就只服务主角。一位船娘可以拒绝承担不起的差事，一名学徒可以留下完成自己的染样，一位同门可以拒绝永远做临时代班；他们的选择即使不导向案件，也应改变自己的工钱、时间、关系或下一步。写每场前至少知道：此人原本在忙什么、知道什么、能做到哪里，以及他为何在数种做法中选了这一种。详表和层级标准以[人物行为与群像总则](人物行为与群像总则.md)为准。

## 轻松幽默的分寸

笑意优先来自人物自己的脾气、彼此熟悉后的接话，以及愿望与现实之间的小落差。段平生会讲究一锅粥，却伸手拿错糖罐；韩青听主角说了半天，能用一句实话把他接住。沈蘅忙了一天仍端着东家的架子，见他真是来约自己，账便忽然核得快了。这些笑点同时让人更亲近。

陈渡的现代感主要表现在看事的方法和自然反应里。偶尔一句带现代节奏的自嘲可以保留，连篇网络梗会让他脱离眼前生活。其他角色听不懂时，可以认真理解、随口顶回来，也可以根本不接；人人都有自己的语言。

一场温暖的日常通常只需一两处有回味的接话，不要求每场抖包袱。笑点之后让事情继续发生，不等配乐提醒观众笑。节日、听曲、吃饭中有些完整场次只负责生活，没有暗中指向命案的尾巴。

陈渡私知原顾之死、程叙面对旧友变化的失落、居民正在失名、有人明确受伤或恐惧时，镜头先尊重眼前的人。前中期程并不知原顾已死，不安排知情哀悼。危机过后，可以由脱险者自己说一句疲惫的笑话，让观众同他们一起松气；别人难受的时候，主角不会为了显得聪明抢着逗趣。

## 陈渡怎样观察、推测和行动

他的极限运动经验留下一个习惯：**先看周围怎样连接，再看哪里与预想不一样。**人物的站位、用力的那只手、一个人反复避开的问题、物件去了哪里，都可以进入视线。经营运动用品店的经历，则让他留意交接、说法与实际需求是否相称。这些长处会迁移到乾朝，古代制度、修行和专业技艺仍需向当地人学习。

| 观众看见的过程 | 写作时要落实的内容 |
|---|---|
| 他注意到一个细节 | 细节先在画面或已有对白中出现，别等他破案时才补出关键东西 |
| 他想到一个超出眼前说法的解释 | 推测要大胆，能改变接下来要做的事；人物可以说“也许”，行动却清楚 |
| 他挑一件事先做 | 找到能区分不同解释的一步：当面相认、重新量一次、改变一个试验条件，或先占住仍可用的接应处 |
| 对方或环境作出反应 | 支持、推翻或缩小猜想；他要看见新信息，能改主意，也能加快下一步 |
| 结果产生代价 | 赢要赢在行动确实奏效；错要错得有缘由，并改变下一次选择 |

这是作者组织因果的方法，不要求人物每次把五步念完。正片往往只用一次视线、一句追问、一个立即执行的决定，便能让观众明白。

**观察不必解释得很小，实施也不必等到所有谜底揭开。**看到几件互相牵连的小事，他可以猜有人在系统地筛选材料，可以提出尝试与旧办法相反的修枢顺序。只要眼前已有足够理由，就先做能得到反馈的那一步；新信息出现，再决定是否扩大行动。用行动获得下一条信息，比站在原地反复说“证据还不够”更有推进感。

他会错。第一次试窗，他看了落差，却错估陌生伤体的配合；一次找路，他把自己能够通过误当成所有人都能通过。错误会使他疼、耽误工夫、失约或丢失物料；下一次他真的换方法。成长要能从前后两次行动里看出来。

## 严肃时的逻辑落在哪里

人物目的要连续。冒役者想拿走旧票，所以先借公事让对方自己交出来；身份将被拆穿，他转而想毁掉已留下的领条。行为随着局势改变，而不是等主角讲完推理才突然发疯。

线索的证明范围要清楚，但说明可以很短。租单记有当日租车的时间和地点，陈渡据此猜测来人可能打算携件离开；车究竟作何用、谁付钱、替谁做事，还要沿这条线追。陈渡此时就能大胆提出“旧票可能比昨夜行刺本身更关键”，然后着手查票，没必要先知道梁朔的姓名才行动。

同伴也有脑子。杜与韩能看出手要往哪里伸，沈能核货程，宁能判断修行扰动，高成礼能复尺与勘验。陈渡的作用是把不同观察连起来，提出值得试的方向，并亲自承担其中一部分。谁提供的新信息，镜头就给谁一次清楚的行动。

对手会解释、遮掩、换办法，也可能抓住主角一次过早的判断反制。一次反转应让前面的细节获得更完整的含义，不能靠刚登场的万能术法推翻已成立的规则。

推测也要碰到他最不愿相信的东西。谢鹤年确实帮过顾家，陈渡仍会在后篇既定线索累积后把恩人列入怀疑，沿命令和经手去核实；这一步会伤及真实感情。大胆既包括试一条新路，也包括明知可能失去庇护，仍把该问的问题问出口。

## 在现有剧情里怎样兑现

### 初醒：会看，也会估错

手上的茧与记忆中的攀岩手不同，镜像跟动作一致，左肩又是眼前能感到的真疼；这些发现使“只是陌生地方”变成“连身体都不对”的怀疑。他仍先尝试一个能看见的出口，失败后承认伤体不听使唤，再向门外求助。允许一句短自嘲，随后继续处理真实恐惧。

### 冒役：先发现来人的目标，再试他的身份

王寿称要查昨夜桥袭，却直接点名要整包北路旧票，领条又空着接收人。前者让陈渡怀疑来人真正的目标，后者让他看见一项可以马上核实的事。桥案确实也可能需要旧票，所以此时仍有其他解释。

陈渡提出请当班人来相认，并让王寿当面写清收件人。杜确认真差就在相邻街口，伍去请，原有九卒分工继续。王寿先设法解释，被当班否认后抢条、拔刃，杜韩石迅速制住。陈渡提出的验证改变了局面，九卒的本领则让这一步真正做得成。

两张纸分别移交，真正旧票仍在顾府。接着查的方向是“为什么一定要这些票”，让主角由被动应付来人，转为主动追对方想要的东西。前三集仍不能凭这一猜想认出终极幕后。

### 隐室：从空间不对，敢猜墙后有东西

内外尺度和旧结构出现具体不合之处，陈渡提出墙后另有空间的解释；高成礼复尺，工匠在已经准许重检的范围内动手。猜测必须先于揭墙，验证必须能区分普通墙厚、错量与真正夹层。陈渡不自动成为古代建筑专家，却敢把一个尚未被别人当回事的观察推到行动。

### 救人与修枢：决定要快，方法要能改

撤离中，陈渡可以先走到仍稳的接应处看路线、尝试把两段运输接起来。别人指出伤者做不到时，他重新安排，把勇气用在组织下一条能走的路上。九卒负责真正挡住敌人，宁和工程人员各自解决不可替代的问题。

替代修枢方案证据尚有限时，也可以在有退出路线的局部先试。失败应带来明确的新认识，例如两个时段叠加的负荷不同，下一次便改变时序，而非原样重试等奇迹。陈渡敢提出新方向，参与修复的人提供各自的判断；最终成功能沿着这些试过、错过、改过的步骤回看。
