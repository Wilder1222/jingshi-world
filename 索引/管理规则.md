## 固定编号

v1.8新增[Q-R01—08](../剧集/配角情感线与关系回收.md)标记配角情感弧；Q-E01—09沿原编号深化，未新增另一组爱情任务。Q-M／E／S／R四类合计41项内部标签，不包括其他专题的选材标签，也不增加正式集数；与任务体系中的同一事件合并使用。爱情与配角情感专题各有2场短样戏，均不计入正式16场或媒体资产。连续性复核包括人物姓名、关系性质、人物知情、南北行程与修复是否在后续仍成立。

v1.8的[Q-X01—08特殊经历](../剧集/任务体系与特殊经历.md)沿用专题内部标签原则，与Q-M／Q-E／Q-S共41个标签，但有共用事件；功法与军阵名称属于世界发展稿，不作为已生成素材，也不因新名自动增加角色、道具或场次编号。

v1.6任务专题的[Q-M01—12](../剧集/主线成长与任务总图.md)、[Q-E01—09](../剧集/情感任务与坚定选择.md)、[Q-S01—12](../剧集/支线与配角任务.md)仅为内部标签；共33张任务卡不等于33个新增事件。共用危机合并写，台本选用时保留前置与回收。仅增专题及导航不新增资产或改正式出场登记；可用`rg Q-M07 剧集`检索。

## 状态分开记录

| 内容 | 当前可用状态 | 含义 |

| 资产文字 | 文字设定／大纲登记／停用 | 有详细卡、仅有大纲依据、或本版不再使用 |

## 检索和更新

直接打开[资产总表](资产总表.md)或[剧集总表](剧集总表.md)，用Ctrl+F搜“韩青”“五卒”“E1a”“GJ-EP03”等。文件名也带编号和名称，可用编辑器的文件检索。

在工作区根目录运行以下命令，可组合类别与剧集筛选；工具只使用本地Python标准库，不需要服务或账号：

```powershell
python 工具/资料管理.py search 韩青
python 工具/资料管理.py search 孔雀青 --type 角色
python 工具/资料管理.py search E1a --type 道具
python 工具/资料管理.py search --type 角色 --episode GJ-EP03
python 工具/资料管理.py search 退伍 --fulltext
python 工具/资料管理.py search P05 --include-inactive
python 工具/同步大纲.py
python 工具/同步美术.py
python 工具/资料管理.py build
python 工具/资料管理.py check
```

默认检索当前登记资料，不混入研究和历史稿，且排除停用资产。`--fulltext`扩展到登记卡的正文；历史变更仅查CHANGELOG.md。全项目全文检索仍可用编辑器或`rg`。

更新工具生成三份带UTF-8 BOM的CSV，位于[导出目录说明](导出/README.md)，可导入表格软件筛选。CSV只是索引导出，四份JSON登记表与正文才是维护入口。

## 后续生成文件放置

### 人物事件图谱

[人物事件图谱](人物事件图谱.html)是作者用的提取与推演层，方法见[专题](../剧集/人物事件与情节关系图谱.md)。维护`索引/数据/图谱人物.json`、`索引/数据/图谱事件.json`；用`python 工具/图谱管理.py build`生成合并数据、HTML与文字明细，用`python 工具/图谱管理.py check`检查引用、顺序、人物覆盖与导出一致性。来源变化提示核对后再生成，不代表工具已自动理解改动。

人物沿用C编号；EV事件、R关系、CE因果边与PL情节线都是图谱内部编号，Q标签仅挂靠原任务和关系弧。图谱不得改变正式72条登记、16场、人物身份或制作状态。事件涉及身份可跨多场、回忆与画外声，不直接用作某场同时在场名单。原始事实先改其设定／大纲／台本，再更新图谱；不要直接维护生成的`人物事件图谱.json`、`人物事件图谱.html`与`人物事件图谱明细.md`。

### 生产媒体与单集文件

复用媒体放在`资产/媒体/对应资产编号/`，例如`资产/媒体/C03/C03-常服正面.png`。将角色的不同衣装、天气状态和表情写在文件名与媒体登记中，不因此增一个人物身份。

单集分镜、配音时间线、镜头片段等专属文件放在`剧集/对应篇章/对应剧集编号/`，例如`剧集/01-归京/GJ-EP01/镜头/`。未进入制作前不批量建立空镜头文件。最终导出放在`成品/对应剧集编号/`，与可复用源资产分开。

新增时先查是否已有同名或别名，分配未使用的编号，补正文和登记表，再运行`build`与`check`。版本发生变化时，选用文件保留稳定入口，删除被替代旧文件并只记录CHANGELOG，禁止用改文件名的方式复用别人的编号。
