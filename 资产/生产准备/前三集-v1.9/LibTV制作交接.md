# LibTV制作交接

2026-09-11核对本机LibTV CLI帮助、技能文档与在线模型schema。本页负责平台输入适配，不另立剧情、分镜或资产母版源；尚未上传、创建画布或触发生成。模型字段须在实际提交前复查。

## 依据与组织

剧情及动作取[发行分镜源](../../../索引/数据/发行前三集.json)，对白按其中dialogue_refs从对应台本解析；人物与场景取现行资产卡及已选媒体。必要控制材料见[必要资产与分镜设计](必要资产与分镜设计.md)，不得以旧任务已选比例代替人物包、场景包或镜头输入验收。

LibTV的workspace为容纳画布的项目，project为画布；实际创建前须确认目标。建议每个发行集一张画布、每场一个普通分组，镜头生成节点采用既有GJ-R编号命名。平台展示shotNumber会按行重排，不能拿它替代本项目稳定镜号；另维护源镜号、平台行id、hiddenUuid及图／视频节点的对应关系。父镜已有子镜时按实际制作粒度选父或子，不能把两层时长重复累加。

## 分镜行与项目字段对应

| LibTV行字段 | 本项目来源与处理 |
|---|---|
| durationSeconds | 父镜或子镜帧差÷24，为最终取用预算；生成器duration另按模型可用值设置 |
| plotDescription | beat、action与本镜剧情目的；附稳定源镜号，不能只留平台顺序号 |
| characters | 角色姓名、当场外貌服装和伤态；characterImageUrl填上传后实际返回的图片地址，不填本机路径或凭空写C编号 |
| shotSize | 从camera提取景别；完整机位与运动另保留在视频提示词 |
| characterAction／emotion | action、performance及角色当场目标，不把作者知道的秘密写成演员已知 |
| sceneTags／lightingAndAtmosphere | 对应场景视角、时段、天气、灯源及当前衣物状态 |
| dialogue／audioEffects | 台本原句与sound；明确画外声、单次响声和跨镜余响，不自动加解释词 |
| imageGenerationPrompt | 当前静态构图、人物和空间关系；不把起身全过程塞进一张图 |
| videoMotionPrompt | 起态→动作与接触→结果；人物运动和摄影机运动分开写，并带本镜接续要求 |
| videoReference.referenceFrameImage | 本镜通过的参考帧图片URL；该字段不是参考视频文件 |

rows可通过CLI节点属性写入。已有定稿分镜应先映射现行内容，避免再次运行脚本文本生成而无意改写。script storyboard会派生图组并逐张启动图片生成，不是无消耗的预览或仅建表命令。节点连线也须限定到当镜需要的参考，不把全剧人物和设定全部灌给一个节点。

## 查询到的模型边界

通过`libtv model search --type video`及`libtv model <modelKey>`读取，查询日期如页首。名称展示可能与schema内部名称不同，匹配使用明确modelKey，写生成器model时按CLI要求使用在线列表的展示名。

| 模型key | 本次schema中的输入条件 | 对本剧的含义 |
|---|---|---|
| star-video2 | 单图1张；首尾帧1—2张；多图1—9张；混合参考总数1—15，图片最多9、视频最多3、音频最多3；时长4—15整数秒 | 3秒取用段不能直接当3秒生成参数；两秒表演节拍也不必各建生成节点。先选完整动作段，再剪出可用部分 |
| kling-v3-motion-control | 同时输入一张图与一条视频；参考视频3—30秒，面向单人角色动作，时长随参考视频 | 可用于适合的单人动作研究；不能据此承诺顾韩双人扶持或五卒合阵可直接迁移 |

schema列出的比例、清晰度和声音开关是参数范围，不证明账号权益、素材校验、实际生成质量或导出效果已通过。本项目24fps是剪辑工作时间基准，不能推定每个模型原生输出24fps。三视图和表情九宫格是备选取用的控制库，不是每次全部上传的硬要求。建模维持暂停。

## 每次提交与回收

提交记录保留源文件哈希、镜号、所选素材路径及哈希、实际上传URL与节点、生成参数和提示词。候选与已选分开；本机文件存在不等于平台已接收，资源节点连线存在不等于模型确实按预期使用。

先验证单镜身份、服装、伤侧、接触、空间和声音，再验证相邻镜首尾及全场节奏。回收实际视频和任务结果后按唯一现行文件管理，历史变化仅记CHANGELOG；不得把本页准备状态改写成已生成、已验收或可直接发布。

## 本地两行草案与更新

[南街分镜草案JSON](LibTV南街分镜草案.json)由[导出工具](../../../工具/LibTV南街分镜导出.py)从现行源派生，包含8秒及7秒两行、台本对白、起始构图说明、动作与机位；本地handoff保留稳定镜号映射、源哈希和实际候选图哈希。该文件不是另一份可独立改写的剧本。

更新源后执行 `python -X utf8 工具/LibTV南街分镜导出.py build`，核对用同命令末尾换为 `check`。导出不会调用LibTV或生成模型；源变化、候选哈希不符会提示重新核对。平台仅使用rows部分，本地handoff不写入节点属性。角色URL、参考帧URL和平台标识保持空值，当前状态为local_draft_not_ready_to_run；须先完成角色与场景绑定、镜头首帧验收、模型选择和逐行审阅，不能直接运行整表生成。
