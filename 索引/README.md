# 检索入口

- [人物事件交互图谱](人物事件图谱.html)：查人物动机、直接关系、事件因果、知情变化与情节线；打开即可使用。
- [图谱文字明细](人物事件图谱明细.md)与[推演方法](../剧集/人物事件与情节关系图谱.md)：支持全文检索、来源追溯与条件分支比较。

- [资产总表](资产总表.md)：编号、别名、分类、标签、状态与已写剧集。
- [剧集总表](剧集总表.md)：四篇工作集／剧情单元及其完成状态。
- [场次资产表](场次资产表.md)：逐场出镜角色、仅画外声、场景和编号道具。
- [管理规则](管理规则.md)：编号、更新入口、全文检索与媒体归档。
- [CSV导出](导出/README.md)：可导入表格软件筛选。
- [目录迁移记录](目录迁移.md)：旧路径对应的新位置。
- [核验记录](核验记录.md)：原文保留、数量、交叉索引与检索检查。

表格可用Ctrl+F检索；人物卡和单集台本也各自提供双向链接。
