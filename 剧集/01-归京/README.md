## 第04至36集分集大纲摘录

以下为大纲原有行动与关系后果，非完整对白台本；统一修改入口为全剧大纲。

<a id="gj-ep04"></a>

## GJ-EP04｜旧衣

状态：**分集大纲**。旧别名：EP04、归京04。日期／时段：廿四。

**当前行动、阻力与结果：**承接前一日追问，韩先说明旧票是北路领支、验货凭单，原顾坚持留下；更深用途他并不清楚。程叙听闻冒役来探望，带衣食、帮办军引核验；今顾以记忆不全解释旧事，接受原本给原顾的亲近。傍晚温九山接报赶到，先查看伤情、确认已稳，让他休息；旧招和运息的系统检查留待第6集，不展开师门履历

**关系变化与后果：**先兑现票的有限用途，再让发小关系成为本集中心。今顾需要当地人的帮助，也正接受并不属于自己的旧情；温到场照看伤者，不让同门排队亮相 今顾把“有人救过我”和“此后安全”分开，先核来敌要人还是要票。温本集末按正常递信行程抵达，只能听九卒转述；明确未安排林中接应，不凭灰袖认人。

<a id="gj-ep05"></a>

## GJ-EP05｜听不懂也要听

状态：**分集大纲**。旧别名：EP05、归京05。日期／时段：廿六。

**当前行动、阻力与结果：**程叙带今顾勾栏听曲，两人对结尾争执，仍把整折听完。今顾不再只附和程记得的口味，认真说自己喜欢的结尾，程嘴上争、仍陪他听完。回程两人约好补窗，买材料给顾伯，许娘在街边卖灯穗

**关系变化与后果：**一次正常出门完整结束，关系从被动接受照顾走到愿意相约做事。今顾开始喜欢这里；第25集重问旧约时，他必须停止以假装记得来维持这份亲近

<a id="gj-ep06"></a>

## GJ-EP06｜路不是这样走的

状态：**分集大纲**。旧别名：EP06、归京06。日期／时段：同日。

**当前行动、阻力与结果：**温正式检查，发现顾砚连多年旧步法也不熟，先按伤后失调处理，教他重新找支点、收势；不施识魂术。今顾确认自己无法靠旧经历解释票据，主动与韩、杜复核桥前林中地形和九阵击退敌人的经过，另循王寿租单查车行，分清两队行动；车行的调借来源把下一步指向沈氏货栈

**关系变化与后果：**温认识的是原顾，异常会累积；今顾以现在能做的核验取代假装记起。九卒准确说明亲见的袭击，不能凭伤口认出雇主；其余老卒在邻近办安置和日用事务 另列林侧介入：巡防回勘只记站位与撤向，灰衣常见，不能作为身份结论；先分别询问九卒，区别亲见刃偏、只听轻鸣和后来转述，不将九人当九份独立来源。

<a id="gj-ep07"></a>

## GJ-EP07｜谁的工钱

状态：**分集大纲**。旧别名：EP07、归京07。日期／时段：廿七。

**当前行动、阻力与结果：**车行曾从沈氏货栈调借王寿租用的车辆。20岁的沈蘅先处理陶七欠薪，再比对借还手续；她主持获授权的长京货栈经营，要求今顾出示相关凭单，不接受只凭顾家名头查账

**关系变化与后果：**沈年轻却已须顶事，仍有经验和权限的边界；陶七先是为自己讨钱的人。两人先认清彼此做事的分寸，亲近尚未发生

<a id="gj-ep08"></a>

## GJ-EP08｜不能只凭一张纸

状态：**分集大纲**。旧别名：EP08、归京08。日期／时段：廿九。

**当前行动、阻力与结果：**车行、货栈和付款经手互证，追到安排冒役的承办人；巡防另循桥前林中走访、五名刺客的住宿登记、撤离见证与承单付款调查行刺。九卒分别作所见范围的证词，不用九人重复同一句话充作九份独立来源。两条行动链出现共同经费经办线索，仍须分别查清

**关系变化与后果：**材料及时交官署。沈认交易，老卒说明亲历，今顾比较疑点；有限辨认与住宿付款提供追查入口，不因灰袖救人就认定其立场，也未证明梁买凶 住宿经手与沿途目击可互证五人撤走；今顾只把介入时点列成问题，不把巧合写成预知，也不为找恩人搁置能查的买凶链。

<a id="gj-ep09"></a>

## GJ-EP09｜年饭

状态：**分集大纲**。旧别名：EP09、归京09。日期／时段：除夕至初二。

**当前行动、阻力与结果：**冒役者被扣，调查等待核办。九卒各凑饭钱，和顾伯忙铺盖、锅灶与年菜；杜仍想等齐开饭，段先给腾出手的人盛热饭，自己却吃到凉的。杜不再催人坐齐，接过段的碗去热，嘴上仍数碗，漏数的恰是端锅的人。饭桌谈亲人、手艺和退伍后的合伙生计，没有新敌人打断。初二，旧案文书使外库加严封存，长京支枢开始本轮补稳，南水关随之失稳

**关系变化与后果：**原顾藏信早于本轮失稳，未穿完好官封。九人分担食宿，军阵领得好的人也会在家常里办岔；杜热饭后接照夜留饭与灾后各自赴约，不把顾伯旧俸写成无限粮饷

<a id="gj-ep10"></a>

## GJ-EP10｜肯作保的人

状态：**分集大纲**。旧别名：EP10、归京10。日期／时段：正月初三。

**当前行动、阻力与结果：**谢鹤年公开担保，争取限定核验与居家候问，承担被追责的名誉风险；条件是材料如实交代。今顾接受，没有把自己的全部推断交给他决定

**关系变化与后果：**谢正式展开为有实际作用的长辈。后来的揭底不能取消这次帮助与感激

<a id="gj-ep11"></a>

## GJ-EP11｜留不住的字

状态：**分集大纲**。旧别名：EP11、归京11。日期／时段：初四。

**当前行动、阻力与结果：**清点外库时，旧构回潮，南水关旧泊位相关水程页出现墨迹扩散、粘连与页边水痕。今顾先查实物受损、人为换页与形成时间，将还能读的部分据实留录；内侧仍无拆检许可，顾伯只知道可见外库结构

**关系变化与后果：**湿损使某段既有文字难读，不会依据现实中的人名自动改写字句。水痕与回潮是复查方向，须另有实测才能判断是否与接合失稳相关

## GJ-EP12｜城外那一单

状态：**分集大纲**。旧别名：EP12、归京12。日期／时段：初六。

**当前行动、阻力与结果：**巡防先控制承单人与罗顺等经手节点；黄祁在离城交接处由守一协缉者参与拘捕，不是普通差役正面击败。现场、五人住宿、付款与撤令经过分别互证，五名执行者逐人核对，不能以一人口供覆盖全队。桥前林中执行链闭合；与冒役链共有的上游经办指向梁所属机构，仍缺本人授权

**关系变化与后果：**九卒证词与官署拘捕相衔接。黄只承认第三方使其不敢继续，未供出可核救者实名；身份与来意仍是独立未解线，不预订下一次救援。韩、杜确认原顾返府后清醒行动，却不知府内断籍决定

**关系变化与后果：**普通造假进入主角生活。程维护旧情的信念第一次直接伤害了另一人的申诉

## GJ-EP14｜灯架下

**当前行动、阻力与结果：**22岁的宁清晏年度巡查入京，先在灯架事故中稳住结构；今顾配合匠人安排撤离。事后她认出宅产核验上自己的签署：此前根据地方“已实勘”呈报同意移交

**关系变化与后果：**宁先以能力和职责登场，也已有判断责任。她不能站在案外只批评坏官

## GJ-EP15｜还没看过，就写好了

**当前行动、阻力与结果：**许娘指出屋内改建细节，沈协助核交割；独立工班出勤证明首次实勘晚于终验签结，与“亲见无人居住”的报告矛盾。宁暂缓执行并要求复核

**关系变化与后果：**指向具体虚假陈述，不把提前写表误作预知未来，更不把许娘直接写成失世者

## GJ-EP16｜那个签押

状态：**分集大纲**。旧别名：EP16、归京16。日期／时段：十四午后。

**当前行动、阻力与结果：**程家短场中，程守成愿退钱，却让儿子换一句“担保时不知情”；程叙拒绝，随后交出文件、承认隐瞒。今顾不删呈文中的程家责任，许娘继续申诉

**关系变化与后果：**程父以具体过错短入，不另开家族阴谋。程失去双方信任；今顾要求朋友如实说明案件责任，自己也须交代会影响协助者的风险；穿越隐秘不成为隐瞒案情的借口

**关系变化与后果：**整集无袭击、无新命案。宁允许一个公务之外的愿望，关系靠真实相处生长

## GJ-EP19｜有人要付账

状态：**分集大纲**。旧别名：EP19、归京19。日期／时段：十六至廿二。

**当前行动、阻力与结果：**沈氏货物暂扣，章秋屏划明工钱与可用担保，保留自己的管事立场。一次收栈，今顾留下帮沈整理受潮货样；她替他掸去领边纸屑，两人忽然站得太近，手都迟了半拍才收回。他主动约她次日晚间去喝热汤，她先说还得忙，最后仍问了时辰；两人到时真赴了约，吃完才各自回家。另场叶扶疏听师父说伤势趋稳，进京送换季衣与材料，发现大师兄接物、练步都与从前不同。众人仍申请核验关印、验货和补卷经手

**关系变化与后果：**沈与今顾先有轻微而双向的心动，一次约见不夹索款或送证据。叶以旧同门关系正式展开；章、叶原有行动保留，商号日常压缩重复工钱说明而来

## GJ-EP20｜他还站在这里

状态：**分集大纲**。旧别名：EP20、归京20。日期／时段：廿三午后。

**当前行动、阻力与结果：**陶七来领余款，工头以当期工簿没有他推责，同工混淆其工次与借住日期；女儿仍认得父亲，却被连问几夜、领几回钱吓住，怕答错而沉默。今顾说明自己亲见的讨薪和上元同行，请经手分开核工牌、支付与实际住处；另一侧旧泊位回潮、临时住处受损，使人更难安置

**关系变化与后果：**活人失名是收入、住处与可核经历被切断的社会后果，不是所有人统一遗忘陶七。亲历能提供核验起点，不能替陈渡证明全部原因

## GJ-EP21｜先离开这里

状态：**分集大纲**。旧别名：EP21、归京21。日期／时段：当日晚。

**当前行动、阻力与结果：**宁与巡查人员按实测确认临水地形异常，将陶七父女转到当时复核仍安全的安置点；住处、食宿与联络落实，身份和欠薪继续核验，旧泊位风险尚未解除

**关系变化与后果：**女儿陪伴父亲有情感价值，不具稳定地形的能力。后续再迁必须来自实测危险边界变化，不能由谁少记住陶七一次触发

## GJ-EP22｜记得，不能代替证据

状态：**分集大纲**。旧别名：EP22、归京22。日期／时段：廿四晨。

**当前行动、阻力与结果：**陆怀真正式接续争议与异常调查，准许限定重检旧库，并调旧契相关登记。勘验吏高成礼记录原位与经手；今顾和宁再次观察外库旧页变化，尚未发现内室

**关系变化与后果：**陆作权限决定，高负责实际勘验；首次只呈现岗位与办事习惯，不加个人长篇身世

<a id="gj-ep23"></a>
