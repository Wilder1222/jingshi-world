## 全剧剧情分镜与AIGC执行规则

本节为已采纳的共同执行规则，与[全剧创作规则](../剧集/剧情结构与推进.md#global-creation-policy)配套，覆盖主线、支线、人物关系、日常、爱情、动作和事件余波。每场按目标、情绪、信息和制作需要采用适合的方法；可省略不适用项，不凑手法数量。前三集中的[五组应用示例](../剧集/前三集重写与生产交接-v1.9.md#aigc-story-to-shot)用于说明执行，不限制本节适用范围。规则已生效，具体模型能力、素材和声画效果仍以实际验证为准。

### 1. 先定观众要读到的变化，再选镜头

每个叙事节拍先写“观众此刻担心／期待什么”和“结束时新知道或感受到什么”，再安排注意顺序。比如先看顾伯伸手，再看今顾退缩，最后看顾伯收手改放水；情绪来自彼此回应。单镜优先承担一个主要变化，可以包含顺序清楚的小动作，不规定只能动一下；若涉及换空间、换时间或多次独立交接，先判断是否需要子镜。

| 表达手段 | 有效用法 | 转成分镜时的落点 |
|---|---|---|
| 反应与动作停顿 | 观众需要看见人物听懂、犹豫、决定或改变方法时，留一次可辨反应 | 明确刺激先到、视线／呼吸／手势后变；选最能看清的一个主反应，不给每句对白配一张惊讶脸 |
| 同框关系与留空 | 用两人距离、物件可取范围和退出通路表现谁在主动、谁可以拒绝 | 用中景同时容纳脸、手与关键物；留空须有剧情用途，摄影机不为制造压迫而改掉真实门位 |
| 画外声与声音延续 | 门外声先入、人物随后望门；上场的环境声延续到下场，可以交代来处或形成对照 | 注明实际声源、听者、先后和是否跨场；非同时空的声画连接要让观众辨明，不把门外人提前生成为门内露脸者 |
| 遮挡与揭示 | 通过已有门框、树干或人的让位，控制信息何时出现 | 遮挡只控制可见信息；交接、救援、拒绝等关键因果要有可核的动作或结果，不能全部藏住 |
| 前景／背景的主次 | 前景处理当前选择，背景少量生活活动交代周围仍在运转 | 同一时刻明确谁是焦点；背景行为有自身目的和连续方向，重要人数与进退不能靠虚化糊过去 |
| 构图、动作与声音照应 | 相似画面再次出现时，以不同回应表现成长或关系改变 | 复用同一场景、物件和可比较的视角，更新真实衣伤与时段；不让同一段视频循环代替人物发展 |
| 景别与节奏变化 | 交代关系用中景，看关键动作再靠近；大变化后让结果被看见 | 避免全片持续推近或碎切；留白也须承载消化、等待或生活感，时长用试读与占位剪辑确认 |

### 2. 图像负责可见起点，视频负责变化过程

身份肖像、服装母版、空间图、剧情起始帧承担不同用途。已有肖像不能直接证明本镜站位、伤侧和手中物正确；正式视频起始帧须先有本镜人物状态、人景绑定与可用空间。参考图只传入其获准范围，场景图中的陌生人物、错位器物与日景光线不自动沿用到剧情夜戏。

编译图生视频提示时，重点写人物怎么动、环境哪里变、摄影机如何响应及先后过程。输入画面已经明确的事实保留在绑定与验收记录中，必要时用简洁位置／衣色描述消歧，避免再塞入全剧设定。文生视频还须补足必要外观与场景信息。此分工参考[Runway图生视频指南](https://help.runwayml.com/hc/en-us/articles/48324313115155-Image-to-Video-Prompting-Guide)关于输入图、动作与时间进程的说明；本作的状态卡与验收方法已纳入共同执行规则。

把“他内心很矛盾”改成可演的过程，例如看向对方、欲伸手又收回、改把物件留在双方之间；这些动作必须来自角色当下选择，不能机械给所有人同一种小动作。气氛词可以保留少量帮助理解，但核心结果要能在画面或声音中核对。

### 3. 一张简明的镜头执行卡

所有分镜按需使用以下执行卡，信息写回现有镜头工作记录与连续性源，不复制第二套台账。表中字段以现有前三集数据为例；其他篇章采用同样的内容要求，按各自当前格式记录，不向大纲强塞镜头字段，也不把模板当作已完成子镜。

| 项目 | 必须说明的内容 | 现行对接位置 |
|---|---|---|
| 来源与观看目的 | 发行集、父镜号、场次；此镜使观众看到什么改变 | `id`、`scene_id`、`beat`、`end_state` |
| 入镜状态 | 谁在哪、看向哪、正拿什么；天气、衣伤、门与灯的状态；接上镜哪一步 | 前镜结果及`blocking_continuity`，事实来源为连续性与资产卡 |
| 起始画面与参考 | 本镜要用的实际文件及其身份／衣装／空间／光态用途；缺项写待制作 | 现有母版登记与依赖；不能把任务号当作图片文件 |
| 人物变化 | 刺激、动作先后、另一人的回应与完成结果；接触物明确谁先松手 | `action`、`performance` |
| 摄影机与环境 | 景别、轴线、视点、一个主运镜目的；背景变化另写，不混成人物运动 | `camera`、`blocking_continuity` |
| 声音与表演节拍 | 谁说哪句、何时听见、画内／画外、接触声的同步点与对口需求 | `sound`、`performance`及待试读声轨 |
| 出镜与切点 | 结束时手、物、眼线、身体重心处于何态；下一镜从哪里接起 | `end_state`、`cut_cue`、`transition_in`及相邻依赖 |
| 时间与后期 | 父镜帧窗、拟取用片段、字幕／文书字层、必要裁切与声音后制 | `start_frame`、`end_frame`及后制任务；实际素材时长另核 |
| 成功条件与替代覆盖 | 哪个行为必须看清，哪些误差会改变情节；怎样拆分仍能保住同一结果 | 对应镜头的复核工作注，不以提示词存在代替验收 |

主体、摄影机、环境、声音分别描述，最后核对它们的同步关系。动作先后写清即可；文字里写了秒数不代表模型会逐帧执行，最终帧窗靠选段和剪辑落实。当前24fps、16:9为工作假设，生成能力、可选时长、参考输入、首尾帧及原生声音须按实际选用模型和入口再核对，不设全模型通用的固定秒数或参数。

### 4. 按可读性拆分复杂动作

先把复杂段落拆成“准备—发生—后果”的可验证节点，再决定哪些节点可以同镜。短片段聚焦一个场合内的明确事件，是[Google视频生成最佳实践](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/video/best-practice)给出的建议；本项目据此采用以下覆盖方法，不据此宣称复杂镜头一定失败或单人固定镜一定成功。

| 本作需要重点验证的组合 | 首选覆盖与必要结果 | 遇到问题时的调整 |
|---|---|---|
| 双人扶持、递物与多人换手 | 同一可读区域呈现承托建立、原持有者退出、人物或物件稳定落位 | 可拆准备与收束，但保留能证明交接的一段；不能一切镜就由另一人拿着、前手已凭空消失 |
| 多人、八马、车体与两波进退 | 建立镜交代锁定空间与数量，局部镜头分别承载已经明确的动作，段末交代位置结果 | 分层预演、核对实例后再制作；不以删人、缩马、改胜负或漏掉第一波退出降低难度 |
| 细小表演同时叠加强运镜 | 先让目光或手势变化清楚，摄影机在需要改变注意时再动 | 先减摄影机变化或背景活动，再决定是否拆镜；保留关键反应的观看时间 |
| 精细文书、器物结构与衣物状态变化 | 关键文字以确定字层后制，器物轮廓和衣伤依选定母版；跨时换衣用明确省略 | 先修有问题的输入状态或独立部件，再验证运动；不能靠动态模糊藏掉决定剧情的字段或错侧伤 |

父镜是叙事与剪辑预算单位，不保证一行对应一次生成。若拆子镜，沿稳定父ID登记未使用的子号，成片子镜帧窗连续、不重叠，其总时长仍等于父镜预算；尚未细分的镜头不预占子号。生成素材可含剪辑余量，但余量不计入发行正片；尾签、黑场和过渡均须纳入所属集预算。前三发行集当前为71父镜、合计555秒，后续各集按自身已定预算执行。重要动作不能只拿起、落下两张静帧便宣称过程通过。

### 5. 首尾衔接、声音和小屏可读性

入镜前先检查上镜留下的实际状态。使用上一段尾帧接续时，要核对它是否已经偏离角色和场景母版；错误尾帧不能继续向后传播。匹配剪辑接的是动作阶段、位置、视线和声场，不必每镜都沿用上一张尾帧；换机位须有与既定空间相容的新起始画面。首尾帧即使都正确，中间接触、行走或物件变化仍须检查。

对白、画外声、环境声、接触声和音乐分开规划。台词先按真实语速试读，把关键停顿留给人物回应；物落声跟随实际接触，门外声保持空间距离，重要信息不被配乐盖住。能否原生出声、是否能稳定对应指定说话者属于待核能力；最终音轨、字幕、文书字层可以单独制作，不让人物因为声音方便而改变出场与知情。

按预期观看尺寸检查脸、手和关键物能否辨认；重要线索不能只藏在全景角落。当前仍按16:9工作；若另做竖屏，要重新核构图、两人距离、物件落点与字幕位置，不能默认横屏中央裁切足够。色彩和音乐可以辅助，却不独自承担谁拿到物件、谁在说话、谁作出决定等必要事实。

### 6. 先验证最影响剧情的部分，再扩到整段

占位剪辑先检查观众是否读懂“触发—回应—结果”，并完成台词计时；片段验证优先覆盖本段最影响剧情的要求，例如同框关系／留物、双人照护／接触或多人空间／换手；本段没有的类型不强加。验证次序不代表已分配付费批次或新增任务。一个段落通过后再向邻镜扩展，先解决共用的起始状态与接续问题。

看到问题先定位所属原因：起始画面错、动作含糊、时长不足、机位遮挡、声音先后错或相邻状态不接，再只调整相关部分。替代覆盖须保留同一剧情结果；通过的脸、衣装、地理与知识边界继续继承。结构检查只证明字段与预算关系，实际验收还要看完整运动、接触瞬间、声音和相邻剪辑；只看首尾静帧不够。可理解的动作、可接续的结果与人物反应，比提示词里堆积“电影感”和抽象情绪更有用。

## 一、固定的身份与制作口径

以下为前三发行集与后续门口单元的特定口径；其他篇章采用所属台本、人物与场景状态，不将本段出场范围、雨伤或道具位置套到全剧。

### 1. 原顾、今顾、陈渡分别指谁

- **原顾：**乾朝顾砚，24岁，八岁拜入归藏山。前三集开头活着回京的人。他有自己的过去、师门、发小、同袍与调查目标。
- **陈渡：**29岁，现代运动用品店合伙经营者，业余攀岩、山地穿越爱好者。现代肉身已在返程途中自然滑坡事故中死亡。
- **今顾：**陈渡进入24岁顾砚身体后的编剧标记。剧中对外仍被叫作顾砚；不是第二张古装脸，也不是原顾失忆。
- **原顾与今顾共用同一古装面容和身体资产。**变化主要来自目光、呼吸、重心习惯、对物品与他人距离的反应。不要靠忽然换瞳色、发色或体格区分。
- 前三集不展示陈渡的现代完整面孔。现代岩壁只出现他的局部手臂、手、绳具与岩面；相关局部不新增一位露脸角色。
- 原顾的原有体能不等于陈渡自动掌握原顾的战斗招式。陈渡也没有法律、档案、医学或古代建筑专家能力。

作者知道：陈渡最后一次攀岩主动放弃难段，搭返程车遭遇自然滑坡，肉身死亡。岩友杨舟乘另一辆车，存活，没有穿越。
