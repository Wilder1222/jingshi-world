## 后续调用

按角色登记的`portrait_master_id`查询母版登记，取`path`作为真实图像输入，并校验`sha256`。C02直接使用C01原图，不另建一张脸。前三集构建工具自动将已选肖像绑定原FACE任务，把图像路径与校验值传入依赖该任务的派生项，并保留尚缺的服装、空间或后制前置。建筑按场景登记的`architecture_master_ids`取得母版；`reference_task_ids`只为对应空间任务及其图像派生传递造型引用，`task_ids`保持为空，不解除平面／夜态前置。引用不会沿共用平面工序把书房陈设串入卧房；次卧可按母版ID读取，但在具体用途确定前不自动投向现行任务。任务编号不能替代图片上传或模型所需的引用地址。

当前选用范围为脸部身份与肖像中可见的妆发；身材、全身服装、背面、细节和动态一致性尚待派生核验。宁清晏的银珠高髻、殷照夜的半束长发、顾砚的束髻及脸部比例以各自原图为基准，文字面貌描述与图像有差异时以母版为准。换装保留身份，未显示的部分必须标明推演。

殷照夜的黑衣登记为本肖像造型，日常浅色衣套仍按[角色服装系统](../角色服装系统.md)制作；不因肖像把黑衣扩为所有剧情常服。顾砚肖像脸部无伤，左肩伤及浅灰干衣按剧情另行派生，不将原顾／今顾生成成两张脸。

## 维护

现行母版放`资产/媒体/所属编号/`，源登记原地更新；经过修图的用户原始媒体保存在`参考/用户媒体/`，登记原文件校验值、修图工具和提示词，不将原始参考作为历史版本清除。替换当前母版后重新校验并标记受影响派生任务待核验，不能把旧产物自动视为匹配新母版。历史变化只记根目录CHANGELOG，不建立历史版本副本；独立参考和用户媒体按项目维护约定保留。选版记录模板只是空表，真实已选母版以本登记为准，不往每次重建的空模板内保存唯一记录。
