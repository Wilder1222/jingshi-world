剧情发展稿 **v1.8** · 美术设定 **v0.8** · 分类管理 **v1** · 更新：2026-09-08。

本轮按“整体紧凑，推进与情节组织更像美剧、韩剧”重整篇章目标、连续因果和关系递进，并按补充要求融入中式的人情恩义、家族师门、家国民生、含蓄表达与节令照应。先读[剧情结构与推进](剧集/剧情结构与推进.md)及其中的[中式叙事补充](剧集/剧情结构与推进.md#chinese-narrative)，再读[全剧大纲](剧集/全剧大纲.md)。三种方法在同一事件中合用；大纲补强归京前段衔接、照夜中段的持续阻力，并将众名从重复揭罪转向新后果与有限时间内的行动，具体结构安排为可调整工作稿。

v1.5已补齐56名现有角色的作者用传记，并增加20个第一阶段情节落点、6场短戏和后三篇18个扩展节拍。选材见[主角与近人传记](设定/人物传记-主角与近人.md)、[人物弧光与伏笔回收](剧集/人物弧光与伏笔回收.md)、[群像与对手传记](设定/人物传记-群像与对手.md)与[多端世界及七篇章推演](设定/多端世界与七篇章推演.md)。这些是可取用的创作素材，不要求全量上屏；既有世界规则、人物硬锁和前三集台本保持各自权威。

当前硬规则与关系依据：[人物行为与群像总则v1.0](设定/人物行为与群像总则.md)、[乾朝社会与制度运行v1.0](设定/乾朝社会与制度运行.md)、[世界观与终局](设定/世界观与终局.md)、[重境、修行与承接机制v1.3](设定/重境、修行与承接机制.md)与[终局多方知情与彼端主体v1.3](设定/终局多方知情与彼端主体.md)。四位主角不设根本利益冲突或爱情零和；旧境真实、接合有限，文书不能改写肉身与记忆，现代事故和两种身份的死亡不可逆。第一阶段权力由谢、皇权、工程与钱粮共同维持、各负其责；河湾有局部拒绝权。未具名岗位已补职务传记草稿，仍不登记角色编号；[幕后群像与权力结构v0.9](设定/幕后群像与权力结构.md)供沿革对照。

本轮确立人物与画面的审美：全员好看、各有特色，以高端华丽古装剧为底子。[美术风格与造型总则](资产/美术风格与造型总则.md)统领角色骨相、衣装、仪态及场景质感，文字方向已分入角色与场景卡。

既定整体语气：日常略带轻松幽默，认真时从细致观察、大胆推测到主动实施。每篇集中回答一个问题，每集以一个主要问题推动行动；感情在选择和相处中逐步变化。主角不替全城处理公共事务；重要支线必须改变主线、人物的关键选择或情感结局。执行方法与现有剧情示例见[叙事风格与主角行动](设定/叙事风格与主角行动.md)，已有前三集本轮未重写。

三位女主继续为沈蘅20岁、宁清晏22岁、殷照夜19岁，均有与男主的双向爱情与独立人生线。宁的克制坚定、殷的鲜活决绝按本作经历发展，不复制外部作品的既定对立或命运；关系见[三位女主与感情线](设定/三位女主与感情线.md)。
