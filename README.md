# 《经世》创作工作区

剧情版本 **v0.7** · 美术设定 **v0.8** · 分类管理 **v1** · 更新：2026-09-07。

当前讨论：[幕后群像与权力结构v0.9](设定/幕后群像与权力结构.md)，推演少数核心人物如何共同维持、又彼此牵制。该专题为结构提案，既有台本和分集登记尚未按它重写。

本轮确立人物与画面的审美：全员好看、各有特色，以高端华丽古装剧为底子。[美术风格与造型总则](资产/美术风格与造型总则.md)统领角色骨相、衣装、仪态及场景质感，文字方向已分入角色与场景卡。

既定整体语气：日常略带轻松幽默，认真时从细致观察、大胆推测到主动实施。执行方法与现有剧情示例见[叙事风格与主角行动](设定/叙事风格与主角行动.md)，已落入前三集修订。

三位女主继续为沈蘅20岁、宁清晏22岁、殷照夜19岁，均有与男主的感情戏。关系见[三位女主与感情线](设定/三位女主与感情线.md)。

资产按角色、场景、道具分类，前三集按集独立保存。每集末尾列所需资产，每张资产卡末尾反查出场剧集与场次。现有内容均为文字创作，图片、配音和视频尚未制作。
