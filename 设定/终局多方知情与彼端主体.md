# 《经世》终局多方知情与彼端主体 v1.3

2026-09-07｜依据“探索终局幕后Boss”共享讨论，对[世界观与终局](世界观与终局.md)、[重境、修行与承接机制](重境、修行与承接机制.md)和[全剧大纲](../剧集/全剧大纲.md)作出的终局补充。世界硬规则仍以重境母稿为准；人物边界以[人物行为与群像总则](人物行为与群像总则.md)为准。本页不新增一位高于四方网络的万能主谋，也不把本页的未命名席位提前做成角色卡。

## 一、本轮要解决的不是“谁比谢更大”

如果所有皇权、宗门与高阶修行者都对长期异常毫无察觉，世界会显得不可信；若每发现一层真相，就再出现一位知道一切的更大反派，前面每个人的责任又会被抹平。

现行答案是：**看见异常、理解异常、能把判断变成行动，始终是三件不同的事。**终局不是一份谁都不知道的总密令，而是少数人各自看见一部分、各自把一部分风险变成授权、工程、钱粮或强制的长期合作。谁都不全知，谁也不能因此免责。

| 位置 | 已经看见或掌握的局部 | 仍然不知道／做不到的部分 | 必须承担的选择 |
|---|---|---|---|
| 承祐帝 | 历年灾异、投入、未撤人数与急令将由谁承担 | 不能仅凭皇权判断某段河岸还能承多大负荷 | 已见差额后仍准附条件推进、未及时撤旧急令 |
| 谢鹤年 | 偏选个案、人员去向、旧案与各席之间能互相施压的材料 | 不能控制旧境变化、调遍工班或令船车凭空到场 | 将成功样本和中央主调包装成唯一叙事，限制复核与陈渡的选择 |
| 工程主事 | 三地相合、工期、测值和骤停的局部风险 | 不掌握接收床位、钱粮和另一侧居民的生活 | 已知强并与现场人数不能同时成立，仍缩报、续作或拒绝错峰 |
| 财赋／转运主事 | 船车、工钱、粮药、账期与结报缺口 | 不能令地面承重，也不能命令另一侧配合 | 已知容量不够，仍先付工料、扣住撤运或预结活人 |
| 温、岳、天一观、太微等高阶修行者 | 自己亲历的失稳、旧构或近场测值 | 修为不等于能读遍全国档案、替全部居民决定去留 | 只为自己实际见到、复测过的结论背书；拒绝给“天道如此”的空白授权 |
| 旧境河湾社群 | 本地水势、岸工、住处、季候与自身撤离压力 | 不知道乾朝中枢为何做出某项批复，也无权替当世决定 | 对本地联系提出条件、拒绝被当作余压出口；其行动会真实改变接合条件 |

这张表不是把河湾社群升格为第五个中央权力席位。它只说明：**另一侧不是可供乾朝调度的空白容量。**四方仍对自己在当世的批准、压报、付款、调相和执行负责；另一侧有权拒绝，不能替他们收尾。

## 二、过去的合作如何变成不同的终局目标

三十年前最早的一次短程互助确实救过两侧的活人。乾朝一侧提供过药粮、道路与人手；河湾一侧也以自己的岸工、错峰和临时接应让那段联系没有立即失稳。后来当世的中央主调把这种互助记成了可扩容的“成功路线”，逐年将不便计入的另一侧条件、失败个案和退出成本压成边注。

到冬至前，各方并不共享同一个终点：

| 位置 | 当前想守住的东西 | 与主角一方真正冲突的点 |
|---|---|---|
| 承祐帝 | 主粮道、国库与皇权对非常通路的最终调度权 | 明知有替代承接正在成形，仍认为不能由现场和地方先决定停用 |
| 谢鹤年 | 自己能解释、筛选并协调的中央路线 | 不肯承认“曾救成”不足以证明“必须永远照旧” |
| 工程主事 | 枢网连续、既有工班与自己对骤停风险的专业判断 | 把局部技术风险包装成不能错峰、不能重排的唯一方案 |
| 财赋／转运主事 | 账期、运力、关系网与可结报的秩序 | 把未抵达的人继续写成可在下一期补齐的差额 |
| 守一执令修士首领（未命名） | 自己能看见的近场相合与旧急令 | 误把“强并或可窥见天人”的私心，带进强取维护组的现场行动 |
| 岳素真等守护者 | 不让旧创伤以“再试一次”重演 | 容易将亲历过的灾难推广为对整组旧路的一刀切封止 |
| 河湾社群 | 不再让自己的河岸、房舍与撤离承受当世单方面的余压 | 不接受被中央报表视为无限接收地，也不替两侧失误承担迁民 |

守一执令修士首领的“破境”诱惑在本作中只能是**错误的理论欲望**：他误以为维持罕见相合能取得通往天人的关键证明，或至少让自己的见解不可替代。重境不是可供吸收的力量源；他不能靠此破境、长生或获得新能力，也不能借一套私人理论洗去工程、钱粮和授权链的责任。这个误判只说明他为什么在明知现场有人时仍拒绝新交接、强取维护组，并与宁清晏的天人初证构成反面映照：宁不是借人命换境界，而是在说清恐惧、边界与责任、并有多人各尽其职时，才得到三十息的有限稳定。

岳素真承接“守境者”的戏剧功能，但不是新反派。她有权坚持：已确认无法修复的**中央强并锚定**必须废止；她不能因此宣称所有自然接合都应永封。她会要求先有小范围、自愿、可退出的复测，而不是被一句“我们会更小心”说服。试验的失败和后来的回雁成功，才分别校正她与工程主事的绝对化判断。

## 三、旧境一端怎样有主体性而不扩张成第二套天下

目前只锁定桃汀、回雁、石门在旧境中所连的同一段河湾。那里有居民、岸工、互助与本地计数方式；它不是白河旧城的遗民乐园，也不等于整个旧境有一个随时可调兵开门的君王。

首次可见的另一侧行动应满足四个限制：

1. **范围有限。**只涉及河湾的堤岸、住处和当季迁移，不补全旧境国号、皇室、地图或百科政体。
2. **证据独立。**用水位标记、对侧撤离痕迹、已约定的灯讯或双方都能读出的计数物，与当世测桩、到达册互相验证；陈渡的感觉不能代替它。
3. **不能救场。**河湾社群可以维护自己一侧、拒绝超量承接、把风险信号送出；不能在最后一刻开门、派军或替乾朝完成撤离。
4. **有拒绝权。**任何保留的局部联系都须写明双方的负荷、期限、退出和停止条件。另一侧的同意不是礼节，而是安全使用的一部分。

这样，旧境从“被人谈论的异常地点”成为同样会受道路、天气、房屋和迁移影响的真实世界；同时顾砚的任务仍只限于这组接合及其造成的具体伤害，不变成跨两界征服或外交大戏。

## 四、可执行的四篇落点

| 位置 | 新增或强化的行动 | 产生的变化 |
|---|---|---|
| 白河07 | 局部重叠中看见河湾一侧自行撤岸、标记水位的痕迹；双方都无法直接讲清全貌 | 首次证明“条件变了”不只是乾朝工程失误，也有另一侧现实在变化 |
| 白河11 | 三地实测与旧案并案时，加入对侧同日水位／撤离计数这一独立对照 | 皇帝、工程、钱粮各自知道到何种程度，不能再混成“所有人被谢骗了” |
| 众名03 | 第一次试验失败时，对侧岸工正处于自身季节性改道，说明替代方法亦必须尊重双边时序 | 失败不是替代方案全错，也不是一方可单独决定何时强开 |
| 众名05 | 岳提出废止已坏的中央锚定、暂不放大其余接合；工程主事仍想拖到完整观测 | 两种真实恐惧正面相撞，主角须以试验、接收和代价证明有限第三路 |
| 众名06 | 御前出现承祐帝自己签过的附条件卷：未撤口径、风险与旧急令后果均在案 | “他早知道到足以负责”成为可见事实，而非事后旁白 |
| 众名08—11 | 回雁的限量承接取得对侧确认；最终两侧各自守住自己的工作面，不互为牺牲品 | 旧境有发言权，却不取代九卒、宁、沈、殷、程、工程人员的救援位置 |

## 五、明确不采用的版本

- 不新增谢鹤年之上的终极主谋、全知国师、天书或第五只“总钟”；
- 不让工程主事或任何执令修士真正借重境破入天人；
- 不让岳素真、温九山或别的善者一句话永久封死全部旧境；
- 不让“旧境之主”统治全部彼端、操控门户、占领当世，或在终局替主角团完成救援；
- 不因增加另一侧视角而减轻当世四方对授权、调相、钱粮和现场伤害的责任。

本页中守一执令修士的个人动机、河湾社群的具体人物和岳的场内措辞均仍可调整；“知情分层”“旧境一端有局部主体性”“拆中央强并而非永封／永开”则随 v1.3 写入现行口径。
