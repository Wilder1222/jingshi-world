# 《经世》创作总纲 v0.1

> 历史v0.1探索稿，保留对照。当前v0.3见[10世界与终局](<../../../设定/世界观与终局.md>)、[11全剧大纲](<../v0.3/11-全剧剧情大纲-v0.3.md>)和[13前三集台本](<../v0.3/13-前三集详细剧本-v0.3.md>)；本文的现代职业、感情归宿与返回通道等旧安排不并行生效。

工作名：《经世》。原对话没有正式选定片名；此名仅用于组织本版文件，不代表用户已经确认，也未作同名检索。第一季工作篇名《归京》。

本版依据《架空穿越设定》完整参考对话重新编整，保留用户明确提出的东方架空、乾朝、穿越男主、显赫军门原身、边军归来、集体沉默与暗中保护、五层故事、深藏幕后、江湖教派、短剧快节奏和城外截杀。新增世界机制、姓名年龄、时间线、结局及集数属于本轮创作建议。

## 1. 观众最先听懂的故事

一个现代人醒在刚被追杀的军门公子身上。满城都认识这张脸，却没人肯告诉他，这个人为什么必须死。

他开始追凶，随后发现原身顾砚亲手安排了自己的死亡，而这场死亡的目的，是让一个不会随世界一起遗忘的人走进来。

**核心追问：一个人被所有记录和亲人忘记以后，还有谁愿意为他承担责任？**

类型：东方架空、悬疑、权谋、低武动作、慢热爱情。观众先进入具体案件，逐渐接触幻想规则。AIGC是制作方式，故事世界不是AI模拟、游戏副本或梦境。

宣传用一句话：**他借死者的身份活下来，却发现死者为他安排的，远不止一条生路。**

## 2. 三个真正撑住全剧的人

**陈渡，借身者。** 二十九岁的现代档案影像整理与资料校勘从业者，醒来后以顾砚身份生活。他擅长辨认记录之间的差异，却不懂乾朝官制、武功和人情。最初只想活着和回家；后来要争取的是：我的选择不能被一具身体、一个死者或一份所谓正史预先决定。

**顾砚，死去的布局者。** 二十四岁，军门之后，真正的边军军人。他既是被害家庭的幸存者，也是把陌生人拉进危险的人。他的遗产包括证据、朋友、敌人，也包括错误。不能把他写成预见一切、从无失误的完美死者。

**谢鹤年，救人也支配人的长辈。** 七十二岁，三朝帝师，守世局定世派的实际主持者。他确实救过顾砚，确实爱过学生，也批准过顾家被清除。他认为少数人应当替天下承担选择的重责，却把其他人拒绝这种选择的权利一并拿走。

沈蘅不是这三人的奖品或接力棒。她掌握商路、粮药与账簿，有自己的失踪亲人和需要养活的工户。她能使任何一方的计划成功，也能明确拒绝。

## 3. 五层故事如何逐层改变问题

| 层次 | 眼前的问题 | 得到的真相 | 下一层压力 |
|---|---|---|---|
| 一：借身追凶 | 谁杀了顾砚，我会不会再被杀？ | 城外刺杀真实；府内死亡由顾砚主动造成 | 他为什么需要一个陌生人接替自己？ |
| 二：军门旧案 | 顾家真的通敌，还是皇权清算？ | 通敌货契被伪造；顾父保护过失名军民，也参与过早期错误处置 | 为什么有人宁肯保住假案，也不能让旧名出现？ |
| 三：失名之人 | 谁能同时修改官档、账本和所有人的记忆？ | 失世确实发生；物、人及相关记忆在当下脱落 | 该如何保存一个还没有完全消失的人？ |
| 四：正史之局 | 谁在决定哪些人应当存在？ | 谢鹤年用跨政权网络执行正史计划，试图掌控外来见证者 | 他救过的城是真的，代价去了哪里？ |
| 五：经世之争 | 世界只能服从一种历史才能存续吗？ | 旧定衡体系能转移灾害，却不能根治；强行统一记录会使损害集中并累积 | 如何承担救人、改制、迁徙和保存历史的实际成本？ |

后层补全前层，不能让前面的遇刺、贪腐、父母之死变成一场没有代价的假戏。所有现实罪行都要分别结账。

## 4. 全剧完整走向：三季，而不是无限套幕后

时长建议：每季36集，每集约3分钟；第一季约108分钟。这个规格服务于创作，未指定发布平台。制作拆镜后可调整单集时长，但不通过重复回顾凑集数。

### 第一季《归京》：他先学会为自己作证

顾砚雨夜在春泽桥遇伏，带伤回到繁华而冷漠的长京。顾府有人备好了药，谢鹤年照常来看他。夜里书房传出异响；再醒来的，是陈渡。

陈渡先靠观察和冒险维持身份，随即被沈蘅识破“你不了解顾砚”。两人因一份商货旧契结盟。刺客腰牌牵出夜枭，夜枭订单指向军需利益，军需旧账又将白河与一个无人记得的军人裴昭带回眼前。

在他们查案期间，码头工陶七开始被熟人遗忘。陈渡亲历变化，保留的记忆成为他的新负担。沈蘅会忘，但愿意依据自己提前留下的见证与可复核物证继续救人。

第24集，府内死亡由完整证据链重新解释：没有第二个入室凶手。第27集，顾砚的完整遗信确认他在等一个无法指定的来客；信也给后来者留下退出的路。

陈渡愤怒，拒绝再为顾砚执行命令。他本可带线索离京，却折返救陶七和受牵连的工户。沈蘅用货运与账据争回主动，陆怀真依法扣押梁朔。季末坐实顾家通敌货契伪造，解除该证据衍生的家属附罪、追回一部分军户抚恤；顾父全案尚待北境证据。陈渡选择北上查白河，身份上的被迫继承第一次变成自己的决定。

闭合：城外行刺执行链、府内死亡方式、关键伪证、主角是否只想逃命。打开：白河失城、来客机制、谁删去了顾砚看到的失败记录。谢鹤年仍是可信又有边界的援手，不用棋盘特写提前宣布他就是幕后。

### 第二季《白河》：他发现最值得信任的人在替别人选择

| 集段 | 行动主线 | 必须兑现的变化 |
|---|---|---|
| 1—6 | 北上追查白河，军中旧识要求陈渡完成只有顾砚会的军务 | 陈渡公开承认记忆与能力缺失，靠韩青、军士及地形共同过关；不装成复活战神 |
| 7—12 | 乾朝军册没有的补给路线，在朔庭记录中仍有不同侧面的痕迹 | 敌国证人先要求取回被扣商旅；主角必须履行交换，世界扩展成为现实利益问题 |
| 13—18 | 九川盟旧路契、太微旧碑和顾父留下的撤离名单互证 | 顾父曾参与封闭一处失世边界，后因见到被牺牲的人转而反对；不是无瑕殉道者 |
| 19—24 | 白河旧址出现短暂结构重叠，沈蘅追得舅父结局 | 沈从简早已死于拘押；无法救回亲人。白河没有隐藏的活人城等主角一键释放 |
| 25—30 | 比对三地处置日期、定衡调拨记录及完整签押，揭开谢的指挥责任 | 谢承认清除顾氏档案、截断保人密旨和筛选断籍案例；感情是真的，操纵也是真的 |
| 31—36 | 谢提出再度封闭北境一处聚落可救长京商路，陈渡尝试在地迁出与多处留证 | 新办法救下一批人，但损失粮道、部分家产与对谢的信任；停止转移灾害的难题不能靠抓谢解决 |

第二季终场：谢把自己保留的一册救灾名簿交出。陈渡逐页看见真实救下的人，也看见同页背面未入总账的边地损失。谢仍有支持者，而且不是所有支持者都图私利。

闭合：白河去向、沈从简命运、顾父选择、谢的真实身份和责任。打开：自然失世与人为加剧的区别，如何在不瞬间毁掉旧保护网的情况下改制。

### 第三季《众名》：他必须提出能让别人活下去的办法

| 集段 | 行动主线 | 冲突与后果 |
|---|---|---|
| 1—6 | 陈渡等人公开边地损害，要求停止全域合籍 | 乾朝、朔庭、南越及海东不肯交出自己的旧录，各有合理顾虑；“公开真相”没有自动带来团结 |
| 7—12 | 在一处有居民同意的失世边缘地试行多处留证、分时迁出 | 先验证名字/实物/关系同时保留是否减缓脱落；失败的第一次仍造成道路丢失，必须救援、调整，不删掉失败数据 |
| 13—18 | 无相教极端支派销毁活证，九川盟内部有人拿失名户遗产偿债 | 民间和江湖也有压迫；沈蘅为公开商号责任承担赔偿，不能用“民间天然正义”完成改制 |
| 19—24 | 找到合籍前各地独立留证的旧工程与灾例，证明正史非唯一解 | 显示不合籍地区也有自然失世，合籍使损失向某些地区集中；谢失去理论上的独占权，却仍指出迁民粮食缺口 |
| 25—30 | 共同制定分段卸载旧枢的方案，先运粮、疏散，再重新连接地方记录 | 皇帝放弃部分封档权，商号让出救灾运力，江湖和教派接受交叉核验；每方付具体代价 |
| 31—36 | 旧枢压力到峰值；陈渡选择关闭用于外界联系的单独通道，将这部分余量留给撤离者 | 救援依赖整季铺成的粮路、地方档库、异地证人，不靠主角喊出一个名字。旧枢分段退出，灾害降至可监测处置的范围 |

**确定结局：**顾砚、裴昭、沈从简不复活。白河不能恢复成原样，但遗属得到姓名、抚恤和迁居资格；遗漏继续被追补。谢鹤年活着交代决策并接受审理，救人贡献成为完整记载的一部分，不能抵销命令造成的死亡。旧守世局拆分为地方观测、救援、保存三个可互查的职责，跨国盟约允许版本并列，重大失世处置要告知受影响者。

陈渡不获得皇位，也不成为新的唯一守史者。他自愿留在这里，以自己的名字开始生活。沈蘅保留经营事业和独立判断，两人的关系在知道彼此真实身份后建立。现代家人可能仍在等待，是他未被抹平的个人代价；不添加“原身在现代苏醒”抵销死亡。

最后一场：白河新立的名碑旁，一个小孩指着空行问是否写错了。陈渡说：“还没找全。留着。”镜头看见百姓正在补名字，世界开始允许不知道，而不是急着填上唯一正确的答案。

## 5. 爽点如何长在人物行动上

| 观众期待 | 可拍的兑现 | 代价/余波 |
|---|---|---|
| 活下来的爽感 | 陈渡不懂军礼，借敌人不敢公开杀人的顾虑逼出见证者 | 对手发现他有异常，伪装时间变短 |
| 推理胜利 | 沈蘅和陈渡用货数、路程、验收手序击破一张通敌货契 | 沈家也曾做过假账，必须开放自己的账让人查 |
| 武力压迫被打破 | 韩青守窄门，陈渡放下栈桥阻断追兵，沈蘅把被扣工人运走 | 船货损失、护卫受伤；不是现代人突然会绝世武功 |
| 身份关系推进 | 沈蘅说“我知道你不是他”，随后给陈渡一份以本人意愿订立的合作契 | 他必须承认无权兑现顾砚的旧承诺 |
| 反将布局者一军 | 主角识破诱导线索，不按遗图离京，改救活证 | 他失去一条更安全的出城路线 |
| 公共正义 | 军户第一次领到曾被冒领的抚恤，顾家一项附罪获撤 | 主角不能把这份胜利扩大成已经证明全案真相 |

每集至少改变一件事：谁知道什么、谁能行动、谁欠谁、谁失去了什么。尾钩交替用危险、证据、决断和关系变化；不每集靠半句话与惊讶表情收尾。

## 6. 本版对旧建议的明确取舍

- 不采用开头拍完整自行致死过程的验证片脚本；它会提前泄底。
- 不采用“莫信先生”“莫信谢……”和谢落子等直指恩师的季末钩子；以完整证据证明责任。
- 不沿用60集缓慢调查的早期节奏，采用36集约3分钟，并提前兑现死亡反转。
- 不把顾氏设成全员记忆免疫的天选血脉；家族优势来自代代保存的技术、岗位和关系，顾砚另有一次稀有事故经历。
- 不采用原身与现代人双向交换、现代秘密组织、无限复活、第二个终极黑手、万能未来预测。
- 不把先帝密旨等同全皇室无罪；被截回的命令不能消除此前的封案、扣粮和政治获益。
- 保留原组织名称作为世界储备，按剧情需求出场；第一季不进行门派轮番介绍。
