## 重建和交接

运行于本机Blender 5.2.1 LTS、GTX 1660 SUPER 6GB、约16GB内存。视频为960×540、24fps材质预演；关键静帧提高采样，非最终交付分辨率。编码使用当前剪映附带FFmpeg的NVENC H.264，路径在交付脚本中明确；该FFmpeg不含libx264，不能套用其CRF参数。

```powershell
& 'D:\software\blender\blender.exe' --background --factory-startup --python-exit-code 1 --python '工具\Blender场景预演.py' -- build
& 'D:\software\blender\blender.exe' --background --factory-startup --python-exit-code 1 --python '工具\Blender场景预演.py' -- stills
& 'D:\software\blender\blender.exe' --background --factory-startup --python-exit-code 1 --python '工具\Blender场景预演.py' -- render all --engine BLENDER_EEVEE
& 'D:\software\blender\blender.exe' --background --factory-startup --python-exit-code 1 --python '工具\Blender场景预演.py' -- background GJ-R02-SH019 --engine BLENDER_EEVEE
& 'D:\software\blender\blender.exe' --background --factory-startup --python-exit-code 1 --python '工具\Blender场景预演.py' -- inputs
& 'D:\software\blender\blender.exe' --background --factory-startup --python-exit-code 1 --python '工具\Blender场景预演.py' -- audit
python -X utf8 工具/三维预演交付.py pack
python -X utf8 工具/三维预演交付.py check
```

两个脚本只维护当前文件。修改三维源后重建受影响空间、相机与渲染，重打包核验；不能只改文档尺寸。资料／图谱／生产包仍按根AGENTS要求构建检查。未获本次明确要求不提交或推送。
