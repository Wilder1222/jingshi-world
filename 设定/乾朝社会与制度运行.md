# 乾朝社会与制度运行 v1.0

2026-09-07｜《经世》世界观正典。本文定义乾朝的公共生活、权力运行与日常反应；世隙、定衡与终局真相仍以[世界观与终局](世界观与终局.md)为准，逐集事件以[全剧大纲](../剧集/全剧大纲.md)为准。

## 一、使用范围与总原则

乾朝不是一个等顾砚来修好的坏世界，也不是穿着古装的现代城市。多数人能把日子过下去，有人凭本事、积蓄和关系过得更好；但家世、财产、身份、地域、关系和运气，会让同样的努力得到极不相同的结果。旧境、重境与主录的工程口径以[重境、修行与承接机制](重境、修行与承接机制.md)为补充。

国家有真实的强制力，家族、雇主、行会和师门也能施加压力；国家不全能，不等于任何人说一句“不愿意”便可不承担后果。反过来，权力能发出命令，也不等于它能凭空变出粮食、船、道路、工匠或可信的人。

一人的实际处境先问四件事：

1. 谁愿意承认他的身份、经历和眼前处境；
2. 谁愿意同他往来、替他说一句话或与他共同承担风险；
3. 他有什么不能轻易被替代的本领、物件或信用；
4. 事情出错时，哪条制度、关系或证据能接住他。

这四件事是社会处境，不是存在资格。户册空白、路引缺失、同乡不再愿意作证，会让人更难找活、申诉、租房、领款或获得救助；它们**不会**直接使肉身消失。严重世隙中的失世是当前侧不可逆的物理联系丧失；制度盲区只会放大谁更难被看见、被接住和被补偿的伤害，不能被写成文书或记忆魔法。

## 二、权力怎样真正运转

### 2.1 强中央，不等于单人全能

乾朝的国家能力来自持续协作，而非皇帝或一名重臣一句话就能把天下推到某处。常见运行链是：

> 皇权定优先级与授权 → 中枢拆解政策和责任 → 财政、军政、工程、地方分别执行 → 商号、宗门、行会与亲族网络补齐缺口 → 现场人员承担实际结果。

任何国家级行动都要能回答：**谁授权、谁出钱、谁执行、谁提供实际资源、谁核验结果、谁承担失败。**答案通常分布在三至五个系统或人物之间。批了钱不等于仓里有粮；有粮不等于道路可走；有船不等于船户会接危险差事；一份急令也不等于地方已经照办。

### 2.2 常设节点与职责边界

| 节点 | 主要职责 | 能做到的事 | 不能替代的事 |
|---|---|---|---|
| 承祐帝与中枢 | 定优先级、任免、重大授权、跨部门裁决 | 许可紧急工程、调动国库与军政资源、决定是否扩大复核 | 不能亲自测枢、运粮、修路，诏令也要经人和物资落地 |
| 政事堂 | 常政、人事、部门冲突和长期政策 | 把皇权意图拆成可执行的责任与期限 | 不能越过专业判断替工程背书，也不能直接占用地方库存 |
| 枢务院与兵部 | 边防、军令、军籍、军需与兵力交接 | 调整军令、核退籍、安排合法护卫 | 不能把退伍者当现役私兵，也不能用军令替代刑审和地方安置 |
| 度支院 | 预算、军费、赈济和付款次序 | 批拨、追问账目、决定一笔预算何时可动 | 批钱不等于实物已到，更不能要求商号无偿垫付 |
| 转运行署与关口 | 仓储、道路、船运、收验、关税 | 协调物资、核发许可、记录实际交接 | 不能凭文书让断路通行，也不能代替承运者承担损耗 |
| 刑审体系（大理寺、京兆府等） | 刑案、证据、责任与执行复核 | 保全证物、接续案件、分层追责 | 不能因相信主角跳过核验，也不能替工程判断风险 |
| 守世局与司天台 | 世隙测候、定衡工程、轮值修行与技术档案 | 报告风险、维护枢位、提出工程方案 | 不天然掌兵、掌钱或决定谁可被牺牲 |
| 州府、里役与地方网络 | 户产、日常治安、现场点验、救助与落地 | 确认当地人数、住处、劳力和实际困难 | 不能在未获资源时承担中央许诺的一切后果 |

守世局是由灾后临时使职逐渐长期化的准技术机构：它有测候、枢站、专项经费、修行者和档案网络，因此难以被一夜替换；但它的工程判断仍须受现场、钱粮、地方与独立核验约束。它不因懂得世隙，就自动拥有军权、财政权或处置人的权力。

日常机构可以采用“常制 + 使职”双轨。常制保证一般官署能继续运转；遇到边防、灾变或大工程时，中枢可设有期限、有范围的使职协调。使职最容易因“暂时紧急”被延长，因此每一次授权都应留下来源、期限、经手与复核路径。

### 2.3 文书、信息与现实

乾朝可稳定使用以下文书层级：

| 文书 | 用途 | 不能被误写成的东西 |
|---|---|---|
| 诏、制 | 皇权的重大决定、授权与处置 | 不是一发出便自然完成的现实 |
| 牒、符 | 部门通知、限令、调拨和执行凭据 | 不是所有经手人都知道完整理由 |
| 状、申 | 下级报告、诉求、点验与风险上报 | 不是报告了就必然被采纳 |
| 券、引 | 通行、资源领取、支付和身份凭证 | 不是人格、权利或事实本身 |
| 账、簿、收验 | 货物流转、工役、支付与交接 | 可以出错、遗漏或被伪造，须同现场互证 |

信息、统计与资源会逐层变形。无稳定住所者、临工、军属、短期雇役和迁徙者，可能被合法却狭窄的统计口径排除；这比“有人改了一张账就抹掉所有人”更常见，也更适合形成可追责的制度问题。核验要比对现场、独立形成的记录、经手人和实际物资，不能以一份漂亮报表替代现实。

## 三、社会位置与日常出路

乾朝没有一条足以概括所有人的单线阶梯。一个人同时可以是军属、匠人、债权主张者、父母、师门弟子或合伙人；不要只用其中一个标签写尽他的人生。

| 常见位置 | 赖以生活的东西 | 现实门槛 | 可自然显出的生活面 |
|---|---|---|---|
| 权门、旧家与官员家庭 | 官位、田宅、姻亲、门生与体面信用 | 政治牵连、家业未必能随时变现、家内期待 | 维持家业、婚事、父辈责任与衰败后的选择 |
| 士子、教习与基层吏员 | 识字、学问、办事经验、荐引 | 求学成本、差缺、上司与等待 | 落第后的谋生、师生关系、留任或离开 |
| 商号东家、管事与小店主 | 本钱、信用、客源、货路和账期 | 货损、租金、合伙权、应收款与流动现银 | 分号、接班、发薪、协商出资与承担风险 |
| 自耕农、佃户与城郊农家 | 土地、水源、劳力、农具与亲族互助 | 农时、租税、借粮、病伤和劳力不足 | 水权、婚迁、丰年仍缺现钱、修渠与赶集 |
| 匠人、船户、医者和艺人 | 技艺、工具、口碑、熟客、场地 | 材料、伤病、师承、演出或接活机会 | 收徒、修船、开铺、传艺、争取署名与报酬 |
| 军人、退伍者与军属 | 饷给、抚恤、同袍经验与家中支持 | 伤病、离家、身份交接、旧技能转用 | 退伍谋生、遗属事务、探亲与重新成家 |
| 长短工、家内雇役与学徒 | 工钱、食宿、契约、雇主信用与介绍人 | 欠薪、离职成本、缺少说话渠道与工具归属 | 换东家、出师、赎清长契、保住第一次机会 |
| 寄居者、流徙者与无稳定住所者 | 临时工作、同乡、客舍、救助与担保 | 居住不稳、补录困难、申诉与医疗成本 | 留下或回去、找到住处、重建关系和信用 |

不同位置之间可以流动，但流动要支付时间、学习、关系或财物的成本。写“有出路”不等于所有人都轻易出头；写“有门槛”也不等于所有普通人只剩绝望。

### 3.1 出生、养育与补录

孩子首先进入家庭、邻里和照料关系，再进入户册。富户可设宴，普通人也会送米、布、鸡卵或搭把手；养育不是只由父母两人完成。

户口申报、收养登记、补报和临时安置是实际存在的渠道。渠道可能遥远、经手人可能失职、担保人可能难找，但“来不及入籍”或“父母流徙”不等于孩子在法理上不配得到照料。制度是否发挥作用，应落在具体环节，而非把身份缺失神秘化。

### 3.2 读书、学艺与第一次谋生

官学、书院、私塾培养经义与文章；铺中教账、工坊授艺、船上带徒培养谋生本领；宗门传授修行及部分专业知识。识字有层次：有人能读货记、船程和订单，却未必写得了经义文章；有人文章好，却不懂与匠人议价。

第一次谋生的难处常是“谁肯给机会”，不只是“会不会”。铺面招雇、同行介绍、同乡牵线、行介撮合都可存在。介绍人可能帮人，也可能压价、偏袒熟人或隐瞒条件；不能把任何一类职业天生写成反派。

雇工关系要在作者层面分清按日、按月、按件、包食宿的学徒与有期限长契：做什么、做到何时、谁出工具、怎么付钱、受伤谁负责。以雇佣和有限长契为主要形式，不额外引入一整套尚未讨论的世袭贱籍制度。

### 3.3 居住、迁徙与成家

腹地的买卖、探亲、赶集不应处处需要特许；长期迁居、边关往来、军区进入和管制物资运输可有不同查验。初到长京的人真正要解决的是短租、押付、水源、可信的活计和生病时有没有人发现，而不只是跨过城门。

女子可以经营、持产、学艺和修行。婚姻要有本人意愿，也会涉及家庭协商；个人财物、婚前产业、共同经营与家族共有财产分别处理。再婚在法理上允许，评价会因家庭、地域和职业圈而异。冲突应来自谁有何种权利、谁承担何种后果，而不是临时把任何女性写成没有民事能力。

### 3.4 生病、衰老、死亡与救助

医疗主要依靠医者、药铺、家庭照料；官办、民间和宗门救助能够兜底一部分，却不会自动覆盖所有人。修行能帮助有限恢复或救险，不取代清创、休养、长期照料和诊病本领。

死亡后分别处理遗体、丧葬、遗产、债务、未成年家属与哀悼；失踪也不同于确认死亡。民俗和丧仪可以表达感情与关系，不必全部是对抗异常的秘术。救助不足、确认迟延与家属失去依靠，都是社会后果，不应用“户绝”一句抹平。

## 四、钱、信用与资源

任何家庭和机构都同时面对三层问题：

| 层面 | 要问什么 | 典型误写 |
|---|---|---|
| 账面所有 | 有多少田、货、房、票或可追索的债权 | 把一份高价货物当成随手可花的现银 |
| 眼前可动 | 今天能付多少粮、工钱、药、船位与押金 | 把商号和国库写成主角的钱袋 |
| 明日来源 | 还能靠什么继续生活、生产和偿还 | 用一次善意支付取消以后所有成本 |

长京的粮、柴、菜、纸、布、木料来自具体村镇、工坊、船队和转运点。粮价上涨时，城里人会发愁，种粮人也未必立即得益：他可能早已卖粮还债；修渠可能改善下季，却要占用当下劳力。庆贺可租彩屏、银盏、花架与衣饰；体面不等于长期拥有一切昂贵物件。

沈氏这样的商号最重要的不是“富可敌国”，而是流通能力：货栈、仓储、账期、船队合约、地方经纪、票券兑现和信用。它既依赖官府许可，也会被关口、税费、征运和风险制约；能在一段链条中提供选择，不能代替全国财政或随时买通边境。

## 五、亲情、恩情、契约与声誉

| 关系力量 | 能保护什么 | 不能自动换来的东西 |
|---|---|---|
| 亲情 | 照料、住处、介绍、共同承担一段困难 | 不能无限替成年人决定人生或替其隐瞒责任 |
| 恩情 | 记得被救、愿意再次互助 | 不兑换终身服从、永远免费劳动或替人选择去处 |
| 契约 | 把工钱、分利、工具、期限和责任写清 | 有纸不等于双方资源和议价能力天然平等 |
| 声誉 | 介绍活计、令陌生人愿先听一句解释 | 不能代替事实；善名不是免罪凭据，恶名也不是罪证 |

这些关系既能托住人，也会制造限制。人物的成长不必每次都写成“学会正确的道理”；有时只是有人终于说清期限、有人允许另一个人离开、有人拿回自己做成的一件东西。

## 六、宗门、商路与地方社会

宗门既是修行传承，也是专业与社会网络：它们可承担修行教育、定衡辅助、医疗救济、山川维护和地方关系。国家以宗籍、师承、境界、责任与活动范围的登记换取秩序和可追责性；宗门以自治、技术和民间信用保留空间。双方相互依赖，谁也不能完全取代谁。

“邪教”是政治、行政与社会评价，不等于道德真相。无相教的地下庇护可以包含真实救助；旧网络中闻策等经手者对债约与路线的滥用，则可以构成控制与犯罪。天一观的公益也不能抵销其方法在具体人身上的边界与误判。普通受助者不因受助自动归附任何组织。

边军、禁军、州军与地方武装有不同补给、命令和社会关系。五卒属于边军退伍网络：他们受军籍、退籍、旧部、伤病、亲人与生计约束。归旌阵给他们真实战力，但不把他们变成顾砚的私兵，也不赋予官署权。

## 七、地方知识与异常的边界

公开世界里，大多数人知道的是修行、危险路段、某座观擅长救险、某个季节要停船或修堤；他们不知道世隙、主录、定衡承压和“失世人数”的完整作者答案。

同样，一名地方经手人可能知道必须封一段路，一名工头知道某种征兆出现就要停工，一名船户知道哪里水急；“知道该做什么”不等于“知道为什么”。信息按职责分层，不能让所有人提前使用终局知识。

民俗多数首先保持为民俗：过桥祈安、给远行者留灯、祭食、出门系绳，可以有审美与情感意义。只有极少数事件后来被证明与异常有真实联系；不能让观众一见到风俗物件，就默认它是钥匙或灾害预警。

## 八、可反复回去的生活空间

| 空间 | 日常真正发生什么 | 最适合承载的关系 | 不自动承担 |
|---|---|---|---|
| 顾府及相邻街巷 | 吃饭、养护家物、练习、访客、分摊开销 | 同袍、家人、原顾与今顾的关系变化 | 所有人每次都来求顾砚解决问题 |
| 沈氏货栈及周边铺面 | 收货、验货、发薪、换班、议价 | 年轻主理者、老管事、经营与爱情 | 主角随手调用无限资金 |
| 春台院及后台 | 排演、修戏衣、散场、争演出机会 | 艺人、匠人、观众与私人约会 | 接头、暗号或公共事故的固定发生地 |
| 天一观生活空间 | 功课、轮值、吃饭、教习、同门玩笑 | 宁与师长、同门、自己的愿望 | 宗门只在救场时存在 |
| 渡口、船上与庇护院 | 载客、修船、做饭、接送、决定去留 | 殷与合作者、受助者的边界 | 受助即必须归附 |
| 城郊集市与生产村落 | 买种、赶集、修渠、送货、婚丧 | 城乡联系、家庭生活与地方后果 | 每次都揭出幕后阴谋 |

视觉上，繁华不等于全画面拥挤。主街、桥头、官署前可以宽阔，支巷、后院与后台形成亲近尺度。普通人的衣服可以干净、合体、配色漂亮；阶层差异更多通过料子、工艺、数量、保养与场合体现，不用人人灰头土脸。上元能完整看完灯，端午能只为竞渡输赢争吵，幸福不必立刻被灾难打断。

## 九、从世界到剧情的使用边界

本文件提供人物遇到社会问题时世界会怎样反应，**不要求把每条制度、职业或日常习惯都改编成顾砚的任务。**春台院可以停演，船可以修，分号可以谈，某些事也可以在镜头外被当事人自己处理；这正说明世界不围着主角转。

顾砚的固定外部主线是：沿顾家旧案与原顾之死，查出仍在追索、利用自己的幕后计划，并在其完成前阻断它，摆脱这场布局对自己人生的控制。详见[世界观与终局第一章](世界观与终局.md#一这部故事的核心)。

筛选需要完整展开的支线时，先问：

1. 这是**谁**的故事？当事人是否有自己的欲望、判断与决定；
2. 它是否改变主线的线索、条件、代价、关键选择、终局，或人物最终的情感结局；
3. 若删去它，顾砚抵达总目标的过程是否发生实质变化。

若答案是否定的，材料仍可作为一处生活细节、背景后果、人物口中的旧事，或压缩成短场；不要为了展示制度、证明主角善良或讲一个道理，硬把它升级成公共事务。

爱情与日常不必夹带线索。它们可以只让人物作出承诺、暴露欲望、改变信任、获得休息或形成节奏；但若反复只证明“人很好”或“相处开心”而没有新的关系变化，便应压缩。三位女主有各自的目标和不依附男主的选择；被重点展开的行动则应在关键处约束、修正、推进或承担同一条核心冲突，而不是变成三部无关的长剧。

## 十、连续性硬锁

- 不把户册、名声、救助资格或社会承认写成决定肉身存在的法术。
- 不把国家、商号、宗门、军阵或任何一个核心人物写成无限资源或万能答案。
- 不把一个大型计划的授权、技术、钱粮、执行和责任全部收给同一人。
- 不把普通人、流民、无籍者或受助者写成天生更配被舍弃、失世或受控制的人。
- 不把所有节日、民俗、约会和娱乐改写成线索、接头、事故或预警。
- 不把顾砚写成长京总管；他可以因偏爱、责任和自己的目标行动，也可以不介入与自己无关的事。
