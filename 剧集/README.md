## 编号与状态

GJ表示归京，ZY表示照夜，BH表示白河，ZM表示众名。EP用于已经按工作集排列的内容；U用于尚未拆成发行集的剧情单元。SC是场次，例如GJ-EP01-SC01的旧别名为1-1。

“详细剧本”表示已有完整场次与对白，仍可能是待试读工作稿；“分集大纲”只有既定单集行动与关系后果；“剧情单元大纲”尚需以后拆集。后两类不建立冒充完整台本的空文件。

剧本与资产分开存放，剧集通过现有C、S、P编号引用资产；人物不因为出现在一集里就复制出另一套编号。剧情调整在相应正文中进行，索引只同步检索信息，不另写一条不同的故事。
