## 固定编号

| 对象 | 格式／示例 | 使用方法 |
|---|---|---|
| 角色身份 | `C03` 韩青 | 沿用C01—C23，新角色顺延；姓名变动不改编号 |
| 主场景 | `S03` 顾府门院等 | 沿用S01—S07，子区`S03-W`仍属S03；`S06-K`属S06 |
| 道具 | `P06` 王寿手写领条 | 沿用原号；`E1a`是证物别名，不另建重复道具 |
| 归京工作集 | `GJ-EP01` | 保留原`EP01`别名，加篇章前缀避免后篇重号 |
| 已写场次 | `GJ-EP01-SC01` | 保留剧本场号`1-1`，是场次而非镜头编号 |
| 后篇剧情单元 | `ZY-U01`、`BH-U01`、`ZM-U01` | 分别是照夜、白河、众名；单元尚未拆为发行集 |
| 将来的镜头 | `GJ-EP01-SC01-SH001` | 进入分镜后才登记，不提前把一场戏算作一个镜头 |
| 将来的声音、特效资产 | `AU001`、`FX001` | 预留格式，当前没有已生成音频或特效文件 |

C01原顾与C02今顾是两个角色身份，共用一套古装脸与身体。C05杨舟仅画外声。前三集共23个身份、21个露脸造型与1个画外声位；这些是制作需求数量，不是已生成媒体数量。现代陈渡的手和绳具不新增露脸角色。

停用编号不复用。P05空灰布袋保留停用卡，不能出现在当前剧集调用表；P13遗信在前三集属于作者追踪的隐去物件，不列为可见道具。

## 状态分开记录

| 内容 | 当前可用状态 | 含义 |
|---|---|---|
| 资产文字 | 文字设定／大纲登记／停用 | 有详细卡、仅有大纲依据、或本版不再使用 |
| 剧情 | 详细剧本／分集大纲／剧情单元大纲 | 是否已有完整场次和对白 |
| 未来媒体 | 未制作／候选／选用／停用 | 只有实际文件生成后才登记媒体版本与选用结果 |

当前未制作图片、配音、音乐、视频或成片。文字设定不等于已选定美术图；工作时长是估算，没有完成配音试读。后三篇各12个剧情单元不等于各12集。

## 哪份内容作为修改入口

- 世界规则、师门及人物长期关系：改`设定/`对应专题；人物行为、关系与群像的硬锁先查`设定/人物行为与群像总则.md`；全剧事件顺序改`剧集/全剧大纲.md`。
- 前三集实际对白、动作和场头：改对应单集文件；前三集共用说明改`剧集/前三集制作约定.md`。
- 角色表演、身份与美术识别：改`资产/角色/`对应卡。角色长线经历仍链接到设定专题，避免在多份长文里各改一遍。
- 全剧共同美术方向：改`资产/美术风格与造型总则.md`；人物与场景细化先改对应卡，再运行`python 工具/同步美术.py`，将四项造型文字同步到`characters.json`的`visual_design`，场景执行文字同步到`locations.json`的`art_direction`。文字造型不自动升级成已生成媒体，也不改变后篇角色的大纲登记状态。
- 场景布局、道具流转与衣伤：改相应场景卡、道具卡及`资产/连续性.md`。
- 每场出镜／声位／调用资产、索引标题、标签、路径：改`索引/数据/`四份源登记表。正文和登记表应在同一次修改中同步。
- 全剧大纲里的集名、行动及剧情单元正文：修改后运行`python 工具/同步大纲.py`，同步四篇目录与72条剧集登记，再生成索引；前三集逐句台本和场次数据不会被该命令改写。
- `档案/`为旧版与拆分前快照，不继续在其中写新剧情。原始快照保留旧措辞，“当前”指其写作时点；实际修改入口以本规则为准。

资产卡与单集文件内的`AUTO`标记区、三张总表、CSV和`检索索引.json`均由工具生成。不要在这些自动区域单独改出场信息，下次生成会覆盖。

## 检索和更新

直接打开[资产总表](资产总表.md)或[剧集总表](剧集总表.md)，用Ctrl+F搜“韩青”“九卒”“E1a”“GJ-EP03”等。文件名也带编号和名称，可用编辑器的文件检索。

在工作区根目录运行以下命令，可组合类别与剧集筛选；工具只使用本地Python标准库，不需要服务或账号：

```powershell
python 工具/资料管理.py search 韩青
python 工具/资料管理.py search 孔雀青 --type 角色
python 工具/资料管理.py search E1a --type 道具
python 工具/资料管理.py search --type 角色 --episode GJ-EP03
python 工具/资料管理.py search 退伍 --fulltext
python 工具/资料管理.py search P05 --include-inactive
python 工具/同步大纲.py
python 工具/同步美术.py
python 工具/资料管理.py build
python 工具/资料管理.py check
```

默认检索当前登记资料，不混入研究和历史稿，且排除停用资产。`--fulltext`扩展到登记卡的正文；查早期写法可在`档案/`单独搜索。全项目全文检索仍可用编辑器或`rg`。

更新工具生成三份带UTF-8 BOM的CSV，位于[导出目录说明](导出/README.md)，可导入表格软件筛选。CSV只是索引导出，四份JSON登记表与正文才是维护入口。

## 后续生成文件放置

复用媒体放在`资产/媒体/对应资产编号/`，例如`资产/媒体/C03/C03-常服正面-v001.png`。将角色的不同衣装、天气状态和表情写在文件名与媒体登记中，不因此增一个人物身份。

单集分镜、配音时间线、镜头片段等专属文件放在`剧集/对应篇章/对应剧集编号/`，例如`剧集/01-归京/GJ-EP01/镜头/`。未进入制作前不批量建立空镜头文件。最终导出放在`成品/对应剧集编号/`，与可复用源资产分开。

新增时先查是否已有同名或别名，分配未使用的编号，补正文和登记表，再运行`build`与`check`。版本发生变化时，选用文件保留稳定入口，旧文件入档案并保留版本号，禁止用改文件名的方式复用别人的编号。
